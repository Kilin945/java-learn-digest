## @Autowired、@Qualifier 與多個候選 Bean 的解析 · 第 3 步

### 概念

當同一個 interface（介面：規定「要有哪些功能」的規格書，本身不做事）有多個實作類別時，Spring 光靠型別找不到唯一答案，會丟出 `NoUniqueBeanDefinitionException`。

解法：用 `@Qualifier` 幫每個候選 Bean 貼上名字標籤，並在注入點（例如建構子參數前）指名要用哪一個名字的 Bean，Spring 就能精準對應。

### 程式碼

```java
// 1. 在兩個實作類別上，各貼一張名牌
@Service
@Qualifier("email")
class EmailNotificationService implements NotificationService { ... }

@Service
@Qualifier("sms")
class SmsNotificationService implements NotificationService { ... }

// 2. 注入的地方，指名要哪張名牌
@Component
class OrderProcessor {
    private final NotificationService notificationService;

    @Autowired
    OrderProcessor(@Qualifier("email") NotificationService notificationService) {
        this.notificationService = notificationService;
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| @Qualifier（限定詞） | 貼在 Bean 上是取名字，貼在注入點上是指名要用哪個名字的 Bean |
| interface（介面） | 規定「要有哪些功能」的規格書，實際做事的是實作它的類別 |
| NoUniqueBeanDefinitionException | Spring 找到超過一個符合條件的 Bean，又不知道選哪個時丟出的例外 |
