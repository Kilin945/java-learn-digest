## 內嵌 Tomcat 與 main() 啟動流程 · 第 2 步

### 概念：@SpringBootApplication 與 main()

每個 Spring Boot 專案都有一個「進入點 class」，上面貼著 `@SpringBootApplication` 這個 annotation（註解）。註解不是邏輯本身，而是給 Spring 框架看的說明標籤，告訴它「這個 class 是整個應用程式的起點，請自動幫我裝好一連串預設功能」。

真正「按下啟動鈕」的動作發生在 `main()` 方法裡，那一行 `SpringApplication.run(...)` 會把整個應用程式組裝並啟動起來——包含前一步教的內嵌 Tomcat。

### 程式碼

```java
@SpringBootApplication
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| @SpringBootApplication | 進入點註解 | 貼在主 class 上，告訴 Spring 這裡是應用程式起點，並自動開啟預設功能 |
| Annotation | 註解 | Java 裡以 @ 開頭的標籤，附加說明給框架讀，不是邏輯本身 |
| main() method | 主方法 | Java 程式執行時第一個被呼叫的方法 |
| SpringApplication.run() | 啟動方法 | 真正組裝並啟動整個應用程式（含內嵌 Tomcat）的呼叫 |
| args | 命令列參數 | 執行程式時從外部傳入的文字參數 |
