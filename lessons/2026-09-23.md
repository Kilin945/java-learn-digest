## Actuator：健康檢查與指標 · 第 2 步

### 概念：Exposing Actuator Endpoints（開放更多監控端點）

Spring Boot Actuator 出於安全考量，預設只曝露（expose）`health` 一個端點。直接打 `/actuator/info`、`/actuator/metrics` 會得到 404。

要打開更多端點，在 `application.properties` 用 `management.endpoints.web.exposure.include` 列出想曝露的端點名稱，或用 `*` 全開。

```properties
# src/main/resources/application.properties
management.endpoints.web.exposure.include=health,info,metrics
```

重啟後即可打：
- `GET /actuator/health` → `{"status":"UP"}`
- `GET /actuator/info` → 自訂資訊（預設多半是空物件）
- `GET /actuator/metrics` → 可查詢的指標清單

> 生產環境注意：`*` 會開放所有端點，其中有些（如 `/actuator/env`、`/actuator/heapdump`）可能洩漏敏感資訊，正式環境建議只列出實際需要的端點，不要圖方便用 `*`。

### 術語表

| 術語 | 定義 |
|---|---|
| endpoint（端點） | Actuator 提供的監控用網址，例如 `/actuator/health`、`/actuator/info` |
| exposure（曝露） | 決定哪些端點可被外部 HTTP 存取，預設多數端點關閉 |
| application.properties | Spring Boot 設定檔，用鍵值對調整行為，不需改程式碼 |
