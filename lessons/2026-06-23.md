## @Configuration 與 @Bean：手動定義 Bean · 第 4 步

### 概念：@Qualifier — 精準點名你要的 Bean

當同型別有多顆 Bean 時，@Primary 標記預設優先選哪顆；而 `@Qualifier("Bean名稱")` 加在注入點前，可以不管 @Primary，直接指定要哪一顆。

**比喻**：@Primary = 招牌菜（不點就上這道）；@Qualifier = 直接跟服務生說「我要那道紅燒肉」。

### 程式碼範例

```java
@Configuration
public class AppConfig {

    @Bean("fastNotifier")
    public Notifier smsNotifier() {
        return new SmsNotifier();
    }

    @Bean("quietNotifier")
    @Primary
    public Notifier emailNotifier() {
        return new EmailNotifier();
    }
}

@Service
public class AlertService {

    private final Notifier notifier;

    // @Qualifier 優先級高於 @Primary，直接拿 fastNotifier
    public AlertService(@Qualifier("fastNotifier") Notifier notifier) {
        this.notifier = notifier;
    }
}
```

### 術語表

| 術語 | 說明 |
|------|------|
| @Qualifier | 加在注入點前，以 Bean 名稱精準指定要哪顆 Bean，優先級高於 @Primary |
| 注入點（Injection Point）| Spring 填入依賴的地方：建構子參數、@Autowired 欄位、@Autowired setter |

### 一句話重點

@Qualifier("名字") 是精準叫單，@Primary 是預設推薦，兩者搭配讓多 Bean 場景井然有序。
