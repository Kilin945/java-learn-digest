## G1 第 2 篇 · 手寫插入排序，只排前 n 個；int key = arr[i] 為什麼不會 NPE

**題目**：給一個 Integer[]（裡面可能有 null），把它排序。盡量不用內建 function。15 分鐘。

### 題目在問什麼
- Integer[] 的格子可以是 null；int[] 不行。
- 不用內建＝不能用 Arrays.sort 之類，要自己寫迴圈。
- 題目沒講 null 放前或後，要先問；今天約定放後面。
- 本篇只講第②步與自動拆箱為什麼不會 NPE。

```java
// 輸入
Integer[] in  = {5, null, 2, 4, null};
// 輸出（null 放後面）
Integer[] out = {2, 4, 5, null, null};
// ①之後：{5, 2, 4, 4, null}，n = 3，第 4 格是舊值，之後由③蓋成 null
```

### 解題思路
1. 因為有 null 不能比大小，所以先分離：非 null 往前搬，n 記個數（第 1 篇）。
2. **因為前 n 格保證是數字，所以只在 [0, n) 做插入排序（本篇）。**
3. 因為排序只動前 n 格，所以最後把 n 之後補成 null。

### 答案
只對前 n 格做插入排序；null 已被擠到 n 之後，迴圈碰不到 null，所以 int key = arr[i] 的自動拆箱不會 NPE，也不需要 null 判斷。

```java
for (int i = 1; i < n; i++) {
    int key = arr[i];                  // Integer 自動拆成 int
    int j = i - 1;
    while (j >= 0 && arr[j] > key) {   // 左邊比 key 大就右挪
        arr[j + 1] = arr[j];
        j--;
    }
    arr[j + 1] = key;                  // 把 key 放進空出來的洞
}
for (int i = n; i < arr.length; i++) arr[i] = null;   // ③
```

### 第 1 輪 · 釐清：插入排序到底在做什麼？key 和 j 各是什麼？
像整理撲克牌：左邊排好，每次拿一張插進正確位置。

```java
// [5, 2, 4]
// i=1: key=2, j=0: 5>2 → [5,5,4], j=-1 → arr[0]=2 → [2,5,4]
// i=2: key=4, j=1: 5>4 → [2,5,5], j=0: 2>4 不成立 → arr[1]=4 → [2,4,5]
// key = 手上要插入的數；j = 往左掃描的指標
// i 在 [1,n)，j 在 [0,i)，都在 [0,n) 內
```

### 第 2 輪 · 反事實：沒有先做①直接跑 int key = arr[i] 會壞在哪？
壞在自動拆箱：編譯器把它改成 arr[i].intValue()，對 null 呼叫方法就是 NPE。

```java
int key = arr[i];              // 實際：arr[i].intValue()
Integer[] arr = {5, null, 2};
for (int i = 1; i < arr.length; i++) {
    int key = arr[i];          // i=1 時 arr[1] 是 null → NPE
}
// 有①、範圍只到 n：[0,n) 全是①寫入的非 null → 拆箱安全
// while 裡的 arr[j] > key 也會拆箱，j 在 [0,i) 內，同樣安全
```

### 第 3 輪 · 連結經驗：先把 null 分出去，在電文欄位處理裡長什麼樣？
電文欄位過濾與組回應就是第①③步；缺的是第②步。

```java
// 典型寫法（簡化）
List<Integer> clean = new ArrayList<>();
for (Integer v : raw) if (v != null) clean.add(v);
// 平常另開 List 丟掉 null；這題要原地，所以用 n 劃界線：
// [0,n) 乾淨區，[n,length) 待補 null 的尾巴
// null 判斷集中在①，②就不用再檢查
```

### 為什麼要懂
線上 NPE 的堆疊常指向一行單純的賦值，知道 Integer 轉 int 會呼叫 intValue() 才找得到原因，也才知道哪些範圍已保證非 null。

### 結論
插入排序只排前 n 格，因為這 n 格都是①寫入的非 null，所以自動拆箱不會 NPE；把 null 判斷集中在①，②就乾淨。

官方文件：JLS 5.1.8 Unboxing Conversion https://docs.oracle.com/javase/specs/jls/se21/html/jls-5.html#jls-5.1.8

### 術語表
| 術語 | 說明 |
|---|---|
| 插入排序 | 像整理撲克牌，左邊排好，每次插入一個數 |
| 自動拆箱 | Integer 賦值給 int 時，編譯器補上 intValue() |
| NPE | 對 null 呼叫方法或存取欄位時丟的錯 |
| 原地（in-place） | 只改原陣列，不另開同樣大的陣列 |
| key | 這一圈要插入的那個數 |
