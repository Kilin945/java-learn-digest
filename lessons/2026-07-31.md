## 內嵌 Tomcat 與 main() 啟動流程 · 第 4 步

### 概念：Changing the Default Port (server.port)

Spring Boot 預設用內嵌 Tomcat 的 8080 port。如果 8080 被別的程式占用，啟動就會失敗（console 顯示「Port 8080 was already in use」）。解法是在 `application.properties` 這個應用程式設定檔裡加一行 `server.port=8081`，讓 Spring Boot 改用指定的 port 啟動內嵌 Tomcat。

```properties
# 檔案位置：src/main/resources/application.properties
server.port=8081
```

重新執行 main() 後，console 會印出：

```
Tomcat started on port(s): 8081 (http)
Started XxxApplication in 2.1 seconds
```

### 完整啟動流程總覽（本主題收尾）

1. 執行 main()，JVM 呼叫進去
2. main() 裡的 `SpringApplication.run(XxxApplication.class, args)` 開始執行
3. Spring Boot 讀取 `application.properties` 裡的設定（例如 `server.port`）
4. 用指定的 port 啟動內嵌 Tomcat
5. console 印出「Tomcat started on port(s): ...」與「Started XxxApplication in ... seconds」代表啟動成功；若 port 被占用則印出「Port ... was already in use」代表啟動失敗

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| application.properties | 應用程式設定檔 | 純文字設定檔，一行一個「鍵=值」設定 |
| server.port | 伺服器埠號設定 | 指定內嵌 Tomcat 啟動時使用的 port，預設 8080 |
