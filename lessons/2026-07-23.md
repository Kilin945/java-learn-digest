## application.yml 結構與設定優先序 · 第 1 步

### 概念：What is application.yml?

Spring Boot 專案常需要一些「設定值」（例如伺服器 port、資料庫連線字串），這些值不應該寫死在 Java 程式碼裡，否則換環境就要重新編譯。

`application.yml` 是 Spring Boot 的設定檔，放在 `src/main/resources` 資料夾底下，用 **YAML** 格式撰寫：

- 格式為 `key: value`
- 用「縮排」（indentation，往右多空幾格）表示階層關係
- 必須用**空白鍵**縮排，不能用 Tab
- 同一層的項目縮排格數必須一致

比喻：application.yml 就像咖啡機外面的控制面板，調水溫、調豆子份量不用打開機殼重新焊電路（改設定不用改程式碼、不用重新編譯）。

### 範例程式碼

```yaml
server:
  port: 8080

app:
  name: MyDemoApp
```

`server` 底下的 `port` 是巢狀結構（nested structure）——一個 key 底下又包著另一個 key，就像資料夾裡有子資料夾。`app.name` 是自訂設定值的範例。

另外還有 `.properties` 格式，用點分隔階層，例如 `server.port=8080`，功能相同，只是寫法不同。

### 術語表

| 術語 | 定義 |
|---|---|
| application.yml | Spring Boot 的設定檔，放專案設定值（port、資料庫連線等），不寫死在程式碼裡 |
| YAML | 一種用縮排表示階層的純文字設定檔格式 |
| Indentation（縮排） | 用空白（不能用 Tab）往右退一階，表示下一層設定 |
| Nested structure（巢狀結構） | 一個設定裡面又包著另一組設定 |
| .properties | Spring Boot 另一種設定檔格式，用點分隔階層（如 `server.port=8080`） |
