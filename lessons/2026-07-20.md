## Starter 依賴：spring-boot-starter-web 幫你帶了什麼 · 第 2 步

### 概念：Embedded Tomcat（內建的網頁伺服器）

昨天學到 Starter 是「已經幫你搭配好的一整包函式庫」。今天拆開這包裡最重要的一樣東西：**Tomcat（一種網頁伺服器軟體）**。

網頁伺服器（web server）的角色像一間店的「店面」：負責聽外部請求（瀏覽器、App）進來，再把資料交出去。

傳統做法要自己下載、安裝、設定 Tomcat，再把程式包進去才能跑。但 `spring-boot-starter-web` 內建（embedded）了一個小型 Tomcat，執行程式就會自動啟動，開始監聽某個 port（埠號）。

```java
// 你只要執行 main 方法，這一行就會啟動內建的 Tomcat
SpringApplication.run(MyApp.class, args);

// 執行後畫面會顯示類似：
// Tomcat started on port(s): 8080 (http)
```

**一句話帶走**：spring-boot-starter-web 幫你把「店面」（Tomcat 伺服器）內建好了，程式一跑就自動開門營業，不用自己另外安裝設定。

### 術語表

| 術語 | 定義 |
|---|---|
| Web server（網頁伺服器） | 負責接收外部請求、回傳資料的軟體 |
| Tomcat | 最常見用來跑 Java 網頁程式的伺服器軟體之一 |
| Embedded（內建） | 打包進程式裡一起帶著走，不用另外裝、另外設定 |
| Port（埠號） | 伺服器對外的「門牌號碼」 |
