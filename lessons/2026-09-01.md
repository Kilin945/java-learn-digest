## 衍生查詢 vs @Query · 第 2 步

### 概念：用 And / Or 組合多個條件

昨天學到 `findByUsername` 這種單一欄位的衍生查詢寫法。今天延伸：把兩個欄位用 `And` 或 `Or` 黏在方法名稱裡，Spring Data JPA 就會自動組出對應的 SQL `WHERE` 條件。

比喻：點餐時說「牛肉麵『而且』加蛋」對應 `And`；說「牛肉麵『或是』雞肉飯都可以」對應 `Or`。

注意：方法名稱裡欄位出現的順序，必須跟參數列表的順序一致。

```java
public interface UserRepository extends JpaRepository<User, Long> {

    // username 相同 「而且」 status 也要相同
    List<User> findByUsernameAndStatus(String username, String status);

    // username 相同 「或者」 email 相同 就算符合
    List<User> findByUsernameOrEmail(String username, String email);
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| And / Or | 寫在方法名稱裡的關鍵字，用來把多個欄位條件組合在同一個查詢方法裡 |
| WHERE 子句 | SQL 查詢裡負責「只挑符合條件的資料」的篩選規則 |

### 一句話帶走

And / Or 就像疊字，把兩個查詢條件黏在同一個方法名稱裡，Spring Data JPA 自動幫你組成對應的 WHERE 子句。
