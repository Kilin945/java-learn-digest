## B6 第 1 篇 · String 不可變：迴圈裡相加的代價；改用 StringBuilder（電文 FILL 補齊組字串）

**題目**：String vs StringBuilder vs StringBuffer?

### 題目在問什麼
- 三種裝文字的類別：String 不能改，StringBuilder / StringBuffer 可邊接邊改。
- 要答到：① 誰可變 ② 迴圈接字串的代價 ③ 該選哪個。本篇講 ①② 與 StringBuilder，StringBuffer 與不可變的設計原因留第 2 篇。
- 場景：固定長度電文，欄位不夠長就補空白（FILL）再依序接起來。題目沒講的：補左還是補右、補空白還是補 0。

```java
// 簡化示意
// 輸入："AB" 寬 5；"CDE" 寬 6
// 輸出："AB   CDE   "（長度 11）
```

### 解題思路
1. 電文是多個欄位串成長串，先確認「接字串」每次做了什麼。
2. **String 不可變 → 每次相加新造一個（本篇）**
3. **改用 StringBuilder，最後 toString 一次（本篇）**
4. StringBuffer 的同步差在哪（第 2 篇）
5. String 為什麼不可變（第 2 篇）

### 答案
String 不可變，每次相加新造字串，迴圈裡接會一直製造垃圾；組電文改用 StringBuilder。

```java
// 典型寫法（簡化）
StringBuilder sb = new StringBuilder(11);
fill(sb, "AB", 5);
fill(sb, "CDE", 6);
String msg = sb.toString();

static void fill(StringBuilder sb, String value, int width) {
    sb.append(value);
    for (int i = value.length(); i < width; i++) {
        sb.append(' ');
    }
}
```

### 第 1 輪 · 釐清：String「不可變」到底是什麼東西不能變？
```java
String s = "AB";
String t = s;      // t 與 s 指向同一物件
s = s + "C";       // 新造 ABC，s 改指向它；舊物件不變
System.out.println(s); // ABC
System.out.println(t); // AB
// toUpperCase()、replace()、substring() 都回傳新字串，沒接住回傳值等於白做
```

### 第 2 輪 · 推演後果：迴圈接 1000 次會發生什麼？
```java
String msg = "";
for (int i = 0; i < 1000; i++) {
    msg = msg + "X";   // 每圈新造字串並複製舊內容
}
// 複製總量 ≈ 50 萬字元，造 1000 個物件，999 個立刻成垃圾；長度 10 倍 → 複製量約 100 倍

StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append('X');    // 只寫尾端，不夠才擴容
}
String result = sb.toString();
```
電文很短、筆數少時差距不明顯；筆數或欄位多時垃圾與 GC 會放大。

### 第 3 輪 · 連結經驗：FILL 補齊的 code 裡長什麼樣？怎麼認出來？
```java
// 典型寫法（簡化）：容易踩雷
String out = "";
for (Field f : fields) {
    String v = f.value;
    while (v.length() < f.width) {
        v = v + " ";   // 雷 1
    }
    out = out + v;     // 雷 2
}
// 單行 a = x + "-" + y 編譯器會一次湊完；迴圈每圈是獨立相加，不會跨圈合併
// 檢查口訣：迴圈裡 String 變數出現 += 或 s = s + ... → 改 StringBuilder
```

### 為什麼要懂
電文組字串在每筆交易的路徑上，筆數一多，用完即丟的字串讓 GC 變頻繁、回應時間抖動；效能報告提到 GC 高、字串物件多時，要先去找迴圈裡的 String 相加。

### 結論
String 內容改不了，所以每次相加都新造；迴圈裡接字串用 StringBuilder，最後 toString 一次。

### 術語表
| 術語 | 定義 |
|---|---|
| 不可變（immutable） | 物件造出後內容不能改，想改只能造新的 |
| StringBuilder | 內部是可加長的陣列，append 寫在尾端，不用每次新造物件 |
| 電文 | 系統之間傳的一筆訊息，這裡指欄位長度固定的文字串 |
| FILL | 欄位值不夠長時補空白（或 0）到固定寬度 |
| GC（垃圾回收） | JVM 自動清掉沒人用的物件 |
| 擴容 | 內部陣列不夠時換更大的陣列並複製舊內容 |
