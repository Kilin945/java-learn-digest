## @SpringBootApplication 與自動組態的原理 · 第 1 步

### 概念：三合一套餐

每個 Spring Boot 專案的主程式類別上都會貼 `@SpringBootApplication`。它其實是三個註解打包成的「懶人包」：

1. `@SpringBootConfiguration` — 這個 class 本身可以拿來寫設定
2. `@EnableAutoConfiguration` — 打開「自動組態」開關（後續步驟深入）
3. `@ComponentScan` — 掃描所在套件裡的元件並交給 Spring 管理

今天只需記住：`@SpringBootApplication` 不是魔法，是三個註解的組合。

```java
@SpringBootApplication   // 三個註解的懶人包
public class MyApp {

    public static void main(String[] args) {
        SpringApplication.run(MyApp.class, args); // 按下開機鈕
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| Annotation（註解） | 程式碼裡 @ 開頭的標記，告訴 Spring 額外資訊 |
| @SpringBootApplication | 貼在主程式類別上的套餐註解，一次打開三種效果 |
| @EnableAutoConfiguration | 自動組態開關，之後步驟細講 |
| @ComponentScan | 掃描套件下的元件並交給 Spring 管理 |
| SpringApplication.run() | 實際啟動應用程式的開機按鈕 |
