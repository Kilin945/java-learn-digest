## application.yml 結構與設定優先序 · 第 3 步

### 概念：Command-Line Arguments Can Override application.yml

application.yml 裡寫的值只是「預設值」。Spring Boot 啟動時可以多打一個命令列參數（command-line argument），它的優先權比 application.yml 高，會蓋掉（override）設定檔裡寫的值。

這是「設定優先序（configuration priority order）」的第一條規則：

> 命令列參數 > application.yml

比喻：application.yml 是便利商店牆上的公告牌（預設價格），命令列參數是店長臨時喊的口頭指令（特價），收銀員會聽臨時喊的那句，不會看牆上舊公告。

### 程式碼

```yaml
# application.yml（公告牌，寫的是 8080）
server:
  port: 8080
```

```bash
# 啟動時多打一個參數，臨時蓋掉公告牌
$ java -jar app.jar --server.port=9090

# 結果：程式實際用的是 9090，不是 8080
```

### 術語表

| 術語 | 定義 |
|---|---|
| command-line argument（命令列參數） | 啟動程式的指令後面額外加上的參數，例如 `--server.port=9090` |
| override（覆寫） | 用一個新的值蓋掉原本已經設定好的值 |
| priority order（優先序） | 同一個設定值出現在多處時，決定聽誰的順序規則 |
