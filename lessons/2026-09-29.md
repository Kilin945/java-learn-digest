## Logging 與結構化日誌 · 第 1 步

### 概念：Logger, Not println

上線的後端服務不該用 `System.out.println` 印訊息，原因：
- 沒辦法關掉、事後也收不回來
- 不分輕重全部混在一起（沒有等級之分）
- 沒辦法選擇輸出目的地（檔案、監控系統…）

改用 SLF4J（日誌門面）+ Logback（Spring Boot 預設實作引擎）：

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

@RestController
public class UserController {

    private static final Logger log = LoggerFactory.getLogger(UserController.class);

    @GetMapping("/users/{id}")
    public User getUser(@PathVariable Long id) {
        log.info("查詢使用者，id={}", id);
        return userService.findById(id);
    }
}
```

`{}` 是佔位符，參數在真正要印出這行時才組字串，比字串相加寫法更省效能也更好讀。

### 術語表

| 術語 | 定義 |
|---|---|
| Logging（日誌記錄） | 程式執行過程中記錄重要事件、狀態、錯誤的動作 |
| SLF4J（日誌門面） | 統一日誌介面規格，程式只依賴介面，底層實作可替換 |
| Logback（日誌引擎） | Spring Boot 預設內建、真正執行記錄動作的套件 |
| Logger（記錄器） | 程式裡呼叫「印日誌」用的物件，通常一個類別一個 |
| {} 佔位符 | 日誌訊息裡先寫 {}，實際值當參數傳入 |
