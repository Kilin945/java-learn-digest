## Spring Security 入門:認證與授權概念 · 第 9 步(收尾總結)

### Putting It All Together: One Request, Start to Finish

大樓比喻:
- **Filter Chain**:大樓門口的一排關卡
- **Authentication**(認證,你是誰):失敗回 401
- **Authorization**(授權,你能做什麼):失敗回 403
- **SecurityContext**:認證成功後放登入者資訊的地方(訪客證)

一個請求的旅程:
1. 進入 Filter Chain
2. 從請求取出帳密
3. `UserDetailsService` 用帳號找人,`PasswordEncoder.matches()` 比對密碼
4. 成功 → 登入者放進 `SecurityContext`
5. 檢查路徑規則(`hasRole`,由上往下,`anyRequest` 放最後)
6. 進 Controller(方法上可再用 `@PreAuthorize` 把關)

### 完整設定

```java
@Configuration
@EnableMethodSecurity
public class SecurityConfig {

  @Bean
  SecurityFilterChain chain(HttpSecurity http) throws Exception {
    http
      .csrf(csrf -> csrf.disable())
      .sessionManagement(s -> s.sessionCreationPolicy(
          SessionCreationPolicy.STATELESS))
      .authorizeHttpRequests(a -> a
          .requestMatchers("/public/**").permitAll()
          .requestMatchers("/admin/**").hasRole("ADMIN")
          .anyRequest().authenticated())
      .httpBasic(Customizer.withDefaults());
    return http.build();
  }

  @Bean
  PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();
  }
}
```

### 為什麼之後要學 JWT
STATELESS 表示伺服器不記住你,每個請求都得自證身分。每次都帶帳密不方便也不安全,實務上改成登入一次拿有時效的通行證(JWT),之後每次出示。

### 術語表
| 術語 | 中文 | 定義 |
|---|---|---|
| HTTP Basic | 基本認證 | 每個請求標頭都帶帳號密碼的最簡單認證方式 |
| Stateless | 無狀態 | 伺服器不記住你,每個請求都要自己附身分證明 |
| JWT | JSON 網路通行證 | 登入後發的加簽名字串,含身分與有效期限 |
| Customizer.withDefaults() | 預設設定 | 用 Spring 預設值開啟該功能 |
