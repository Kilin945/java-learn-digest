## Bean 的 scope 與生命週期 · 第 1 步

### Bean Scope — 認識 Singleton（單例）

**Scope（作用域）** 決定一個 Bean 被建立幾次、存活多久、和誰共用。

Spring 預設 scope 是 **Singleton**：整個容器只建立一個 Bean 實例，所有注入點共用同一個物件。不標 `@Scope` 就是 singleton。

**比喻：** 公司只買一台咖啡機，不管誰要喝，都用同一台。

```java
@Component          // 預設 scope = singleton
public class CoffeeMachine {

    public String brew() {
        return "☕ 好喝（by " + this.hashCode() + "）";
    }
}

@Service
class ServiceA {
    @Autowired CoffeeMachine machine;   // 拿到同一台
}

@Service
class ServiceB {
    @Autowired CoffeeMachine machine;   // 還是同一台
}
// serviceA.machine.hashCode() == serviceB.machine.hashCode() ✅
```

### 術語表

| 術語 | 中文 | 說明 |
|------|------|------|
| Scope | 作用域 | 控制 Bean 被建立幾次、存活多久的規則 |
| Singleton | 單例 | 整個容器只建一個 Bean 實例，所有注入點共用 |
| Instance | 實例 | 用 new 生出來的具體物件，佔記憶體的東西 |
| hashCode() | 雜湊碼 | 物件的身分證號碼，可驗證兩變數是否同一實例 |

### 重點

Singleton = 容器只造一個，所有人共用；不標 `@Scope` 就是 singleton。
