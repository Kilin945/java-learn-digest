## @Value 與 application.properties 讀設定 · 第 2 步

### 概念：Default Values with @Value（預設值）

昨天學會了 `@Value("${key}")` 從 `application.properties` 讀設定值。但如果設定檔忘了寫某個 key，Spring Boot 開機時會直接失敗。

解法：在 `${}` 裡面加冒號（colon）＋ 預設值，格式是 `${key:預設值}`。

- 有寫這個 key → 用設定檔裡的值
- 沒寫這個 key → 用冒號後面的預設值，程式照常開機

### 程式碼

```java
// 昨天的寫法：properties 裡沒有 server.name，開機就會失敗
@Value("${server.name}")
private String serverName;

// 今天的寫法：加上冒號 + 預設值
@Value("${server.name:MyDefaultServer}")
private String serverName;
```

### 術語表

| 術語 | 定義 |
|---|---|
| Default value（預設值） | 設定檔沒有提供該 key 時，程式自動使用的備用值 |
| Colon syntax（冒號語法） | `${key:預設值}` 中用「:」分隔 key 與預設值的寫法 |
| Startup failure（開機失敗） | Spring Boot 因缺少必要設定值，啟動階段直接報錯無法啟動 |
