## Actuator：健康檢查與指標 · 第 1 步

### 概念

Spring Boot Actuator 是官方內建的監控模組，會自動幫應用程式開出一批「端點（Endpoint）」，讓外部可以在不動業務程式碼的情況下查詢應用程式的運作狀態。

比喻：Actuator 就像車子的儀表板——不用打開引擎蓋（不用看程式碼內部），就能從水溫、油量、警示燈（各個 endpoint）知道車況。

今天只學最基本的 `/actuator/health` 端點：打這支網址會回傳 `UP`（正常）或 `DOWN`（異常）。

### 程式碼

```properties
# application.properties
# 開放 health 端點對外存取
management.endpoints.web.exposure.include=health
```

```bash
# 啟動 App 後測試
curl http://localhost:8080/actuator/health

# 正常回應
{"status":"UP"}
```

（前提：pom.xml / build.gradle 已加入 `spring-boot-starter-actuator` 依賴。）

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Actuator | 監控探針 | Spring Boot 內建模組，自動開出健康狀況相關的網址 |
| Endpoint | 端點 | 一個可以打的網址，打了會回傳特定用途的資訊 |
| Health Check | 健康檢查 | 詢問 App 是否正常運作，回覆通常是 UP 或 DOWN |
