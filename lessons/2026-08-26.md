## Entity 對應：@Entity / @Id / 關聯 · 第 1 步

### 概念
- **Entity（實體）**：一個對應到資料庫某張表的 Java class，每個物件（instance）代表表裡的一列資料。
- **@Entity**：貼在 class 上的注解，告訴 Spring / JPA 這個 class 要被對應成資料表。
- **Primary Key（主鍵）**：表裡用來唯一識別每一列資料的欄位，不可重複、不可為空。
- **@Id**：貼在某個欄位上，宣告該欄位是主鍵。

@Entity 與 @Id 是天生一對：先用 @Entity 宣告「這是一張表」，再用 @Id 標出「這欄是身分證欄位」。有了完整的 Entity，前一天學的 `JpaRepository<Entity型別, 主鍵型別>` 才知道要存取的資料長什麼樣子。

### 程式碼
```java
@Entity
public class User {

    @Id
    private Long id;

    private String name;
    private String email;

    // getter / setter 先省略
}
```

主鍵如何自動產生（不用手動指定數字）留待下一步教學。

### 術語表
| 術語 | 定義 |
|---|---|
| Entity（實體） | 對應資料庫某張表的 Java class |
| @Entity | 標記 class 對應成資料表的注解 |
| Primary Key（主鍵） | 唯一識別每一列資料的欄位 |
| @Id | 標記某欄位為主鍵的注解 |
