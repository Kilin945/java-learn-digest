## Spring Data JPA 與 Repository 介面 · 第 5 步

### 總結：Repository 是你的資料存取工具箱

Spring Data JPA 的 Repository 介面把四種能力整合在一起：

1. **繼承 JpaRepository** → 自動取得 CRUD（save/findById/findAll/deleteById...）
2. **方法名稱查詢（Derived Query）** → 依命名規則自動產生查詢，如 `findByEmail`
3. **@Query + JPQL** → 複雜條件自己寫查詢語法，搭配 `@Param` 綁定參數，回傳常包成 `Optional`
4. **Pageable / Page<T>** → 加上 `Pageable` 參數即可自動分頁與排序，`Page<T>` 額外帶總筆數、總頁數

```java
public interface MemberRepository extends JpaRepository<Member, Long> {

    Optional<Member> findByEmail(String email);

    @Query("SELECT m FROM Member m WHERE m.age >= :minAge AND m.city = :city")
    List<Member> findActiveMembers(@Param("minAge") int minAge,
                                     @Param("city") String city);

    Page<Member> findByCity(String city, Pageable pageable);
}

// 使用端
Pageable pageable = PageRequest.of(0, 10, Sort.by("name").ascending());
Page<Member> result = memberRepository.findByCity("台北", pageable);
```

### 術語表
- **Repository**：資料存取介面，代表跟資料庫溝通的合約，你只寫介面，Spring 自動生實作。
- **Derived Query**：靠方法名稱的命名規則（find/By/And/OrderBy...）自動產生查詢邏輯。
- **JPQL**：很像 SQL，但操作的是 Java 物件（Entity）而不是資料表的查詢語言。
- **Pageable**：封裝「第幾頁、一頁幾筆、怎麼排序」的物件，丟給 Repository 方法就會自動分頁。

### 心智圖
你只描述「要什麼」，不必寫「怎麼拿」——這是 Spring Data JPA 的核心精神，也是 Repository 這個主題的畢業重點。
