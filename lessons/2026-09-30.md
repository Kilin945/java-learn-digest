## Logging 與結構化日誌 · 第 2 步

### 概念:Log Levels(日誌等級)

SLF4J 提供五種等級,由輕到重:

- **TRACE**:最細,幾乎每一步都印,平常關掉
- **DEBUG**:開發除錯用,想看變數目前的值
- **INFO**:正常流程的重要節點,例如「訂單建立成功」
- **WARN**:還沒出事但快出事了,例如「庫存快見底」
- **ERROR**:真的出事了,通常搭配例外(exception)

上線後平常只留 INFO 以上,避免 log 檔被灌爆;要追蹤問題時,把特定套件(package)臨時調成 DEBUG 即可,不用改 Java 程式碼、不用重新部署。

### 程式碼:依等級記錄

```java
private static final Logger log = LoggerFactory.getLogger(OrderService.class);

public void process(Order order) {
    log.debug("開始處理訂單 {}", order.getId());
    log.info("訂單 {} 建立成功", order.getId());
```

### 程式碼:在設定檔調整等級

```properties
# application.properties
logging.level.root=INFO
logging.level.com.example.myapp=DEBUG
```

### 術語表

| 術語 | 定義 |
|---|---|
| Log Level(日誌等級) | 訊息的嚴重程度標籤,由輕到重:TRACE < DEBUG < INFO < WARN < ERROR |
| Root Logger(根紀錄器) | 沒有另外指定時,整個專案預設套用的等級 |
| Package(套件) | Java 用資料夾式命名分類程式碼,可針對它單獨設定 log 等級 |
| application.properties | Spring Boot 放設定值的檔案,改這裡不用動 Java 程式碼 |
