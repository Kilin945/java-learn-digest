## @Configuration 與 @Bean：手動定義 Bean · 第 5 步

### 概念：@Scope — Bean 的作用域

Spring 建好的 Bean 預設是 **Singleton（單例）**：整個容器只建一個實例，所有注入點共用同一個物件。

需要「每次都全新、互不干擾」的物件時，改用 **Prototype（原型）**：在 `@Bean` 方法上加 `@Scope("prototype")`，Spring 每次交出 Bean 時都重新 `new` 一個。

**比喻**
- Singleton = 公司共用印表機（一台，大家共用）
- Prototype = 一次性紙杯（每次拿一個新的）

### 程式碼範例

```java
@Configuration
public class AppConfig {

    // Singleton（預設）
    @Bean
    public MessageFormatter sharedFormatter() {
        return new MessageFormatter("shared");
    }

    // Prototype：每次注入 / getBean 都建新物件
    @Bean
    @Scope("prototype")
    public MessageFormatter freshFormatter() {
        return new MessageFormatter("fresh");
    }
}

@Component
public class ScopeDemo {
    @Autowired ApplicationContext ctx;

    public void check() {
        // true — singleton 是同一個實例
        System.out.println(ctx.getBean("sharedFormatter") == ctx.getBean("sharedFormatter"));
        // false — prototype 每次都新建
        System.out.println(ctx.getBean("freshFormatter") == ctx.getBean("freshFormatter"));
    }
}
```

### 術語表

| 術語 | 說明 |
|------|------|
| `@Scope` | 宣告 Bean 作用域的注解 |
| Singleton | 全容器只建一個實例（預設值） |
| Prototype | 每次請求都建立新實例 |
| `ApplicationContext` | Spring 容器核心介面，可直接 `.getBean()` 取得 Bean |
