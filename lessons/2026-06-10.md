## IoC 與依賴注入：為什麼不要自己 new · 第 5 步

### 概念：When Two Beans Compete — @Primary & @Qualifier

當同一個介面有多個實作 Bean 時，Spring 不知道要注入哪一個，需要明確告知：

- **@Primary**：貼在實作 class 上，代表「預設首選」，沒點名就選它
- **@Qualifier("beanName")**：貼在注入點（建構子參數），點名要哪個 Bean；優先權高於 @Primary
- **Bean 預設名稱規則**：class 名稱首字母小寫，例如 `SmsNotificationService` → `"smsNotificationService"`

### 程式碼範例

```java
public interface NotificationService {
    void send(String message);
}

@Service
@Primary  // 預設選 Email
public class EmailNotificationService implements NotificationService {
    public void send(String message) { System.out.println("Email: " + message); }
}

@Service
public class SmsNotificationService implements NotificationService {
    public void send(String message) { System.out.println("SMS: " + message); }
}

// 沒加 @Qualifier → 注入 EmailNotificationService（@Primary）
@RestController
public class OrderController {
    private final NotificationService svc;
    public OrderController(NotificationService svc) { this.svc = svc; }
}

// @Qualifier 點名 → 注入 SmsNotificationService
@RestController
public class AlertController {
    private final NotificationService svc;
    public AlertController(
        @Qualifier("smsNotificationService") NotificationService svc
    ) { this.svc = svc; }
}
```

### 術語表

| 術語 | 說明 |
|------|------|
| @Primary | 多 Bean 衝突時的預設首選標記 |
| @Qualifier("name") | 在注入點點名指定 Bean，優先權高於 @Primary |
| Bean 名稱 | Spring 預設以 class 名稱首字母小寫命名 |
