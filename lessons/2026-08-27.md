## Entity 對應：@Entity / @Id / 關聯 · 第 2 步

### 概念：Fields become Columns（欄位怎麼變成表格欄位）

昨天學到 @Entity 把 class 標記成一張表、@Id 標記主鍵。今天往下一步：class 裡除了 @Id 之外的一般欄位，會怎麼變成資料表的欄位。

把 Entity class 想成「一張申請書範本」，範本上每一個空格（欄位）就對應資料表裡的一個欄位（column）。在 class 裡多宣告一個 `private` 欄位，JPA（Java Persistence API，一套幫你把 Java 物件自動存進資料庫的工具）就會自動在資料表建一個對應欄位，不用額外設定。

命名轉換：Java 習慣駝峰式命名（camelCase，例如 `publishedYear`），資料庫欄位習慣蛇形命名（snake_case，例如 `published_year`）。Spring Boot 預設自動幫你轉換。

```java
@Entity
public class Book {

    @Id
    private Long id;

    private String title;

    private String author;

    private Integer publishedYear;  // 資料表欄位會自動變成 published_year
}
```

**一句話帶走**：Entity class 裡每多一個一般欄位，資料表就自動多一個欄位，Java 的駝峰命名會自動變成資料庫的底線命名。

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Column | 欄位 | 資料表裡的一個直欄，例如「書名」欄 |
| camelCase | 駝峰式命名 | Java 變數常用寫法，第一個字小寫，後續單字開頭大寫，例如 publishedYear |
| snake_case | 蛇形命名 | 資料庫欄位常用寫法，全小寫、單字間用底線連接，例如 published_year |
