## MockMvc 測 Controller · 第 2 步

### 概念
- `mockMvc.perform(get("/hello"))`：叫 MockMvc 假裝送出一個 GET 請求到 `/hello`。
- `.andExpect(...)`：檢查剛剛那次請求的回應符不符合期待，可以一直串接多個。
- `status().isOk()`：檢查 HTTP 狀態碼是不是 200（成功）。
- `content().string("...")`：檢查回應內文是不是跟指定字串完全一樣。
- 這些檢查動作統稱「斷言（assertion）」——斷定某件事應該為真，不是就讓測試失敗。

### 程式碼
```java
@WebMvcTest(HelloController.class)
class HelloControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Test
    void helloShouldReturnGreeting() throws Exception {
        mockMvc.perform(get("/hello"))
               .andExpect(status().isOk())
               .andExpect(content().string("Hello, Spring Boot!"));
    }
}
```

### 術語表
| 術語 | 中文 | 定義 |
|---|---|---|
| perform | 執行 | 送出模擬的 HTTP 請求 |
| andExpect | 並且預期 | 檢查回應是否符合條件，可串接多個 |
| status().isOk() | 狀態碼 200 | 檢查回應狀態碼是否為 200 |
| content().string(...) | 內容比對 | 檢查回應內文是否與指定字串相同 |
| assertion | 斷言 | 斷定某件事應為真的檢查動作 |
