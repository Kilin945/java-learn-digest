## 內嵌 Tomcat 與 main() 啟動流程 · 第 3 步

### 概念：讀懂啟動時的 log 訊息

Spring Boot 執行 main() 後，console（終端機視窗）會印出一連串 log（紀錄訊息）。就像發動汽車後儀表板燈號閃過、最後亮起「引擎已發動」的綠燈一樣，Spring Boot 也有兩行關鍵訊息代表啟動成功：

```
... Starting DemoApplication using Java 17
... TomcatWebServer   : Tomcat started on port(s): 8080 (http)
... DemoApplication   : Started DemoApplication in 1.876 seconds
```

- `Tomcat started on port(s): 8080` → 內嵌 Tomcat 已經在 8080 這個 port（連接埠）準備好接收請求。
- `Started DemoApplication in X seconds` → 整個應用程式（Spring 容器 + Tomcat）全部啟動完成，可以開始測試 API。

若看到：

```
Web server failed to start. Port 8080 was already in use.
```

代表 8080 這個 port 已經被別的程式（常是自己忘記關掉的舊 Spring Boot）佔用，需先關閉舊程式，或換一個 port 再試。

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Console | 終端機視窗 | 執行程式時顯示過程文字訊息的黑底視窗 |
| Log | 紀錄訊息 | 程式執行過程中印出的文字記錄 |
| Port | 連接埠 | 電腦上區分不同網路服務的號碼 |
| Port already in use | 埠號已被佔用 | 該連接埠已被其他程式使用，導致啟動失敗 |

### 一句話重點

看到「Tomcat started on port(s): 8080」與「Started XxxApplication in X seconds」，代表 Spring Boot 已成功啟動。
