## MockMvc 測 Controller · 第 3 步

### 概念：用 jsonPath() 檢查 JSON 欄位

`content().string(...)` 是整包字串死板比對，欄位順序、空格稍有不同就會失敗，不適合拿來測 JSON 回應。改用 `jsonPath()`：用路徑字串（如 `$.name`）指出 JSON 裡的特定欄位，只針對這個欄位斷言，不受其他欄位影響。

### 範例程式碼

```java
mockMvc.perform(get("/api/users/1"))
    .andExpect(status().isOk())
    .andExpect(jsonPath("$.id").value(1))
    .andExpect(jsonPath("$.name").value("Alice"));
```

假設 `/api/users/1` 回傳 `{"id":1,"name":"Alice"}`，兩個 `jsonPath` 斷言各自獨立檢查 id 與 name，失敗時能明確指出是哪個欄位出錯。

### 術語表

| 術語 | 定義 |
|---|---|
| JSON | 用 `{"key":"value"}` 格式包裝資料的文字，是常見的 API 回應格式 |
| jsonPath() | 用路徑字串指出 JSON 裡的特定欄位，讓斷言只針對該欄位檢查 |
| $ | 代表 JSON 最外層根節點，後面接 `.欄位名` 往內找值 |
