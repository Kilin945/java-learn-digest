## @DataJpaTest 等測試切片 · 第 1 步

### 概念

之前測 Controller 時,可以用 mock Service 頂替,不用啟動整個應用程式。今天學的是測更下面一層的 **Repository**(負責跟資料庫存取資料的程式)。

如果測 Repository 也要啟動整個應用程式(所有 Controller、Service、設定),會很慢、很笨重。

**@DataJpaTest** 是 Spring Boot 提供的一種 **test slice(測試切片)**:只啟動跟資料庫存取相關的部分(Repository、Entity、資料庫連線),Controller、Service 完全不會被啟動,測試跑得快很多。

它還會自動準備一個 **in-memory database(記憶體資料庫,通常是 H2)**,每個測試結束後資料會自動 **rollback(回滾)**,不會弄髒真正的資料庫,測試之間也不會互相干擾。

### 程式碼

```java
@Entity
class Book {
    @Id @GeneratedValue
    Long id;
    String title;
}

interface BookRepository extends JpaRepository<Book, Long> {
}

@DataJpaTest
class BookRepositoryTest {

    @Autowired
    BookRepository bookRepository;

    @Test
    void savesAndFindsBook() {
        Book book = new Book();
        book.setTitle("Clean Code");
        bookRepository.save(book);

        assertThat(bookRepository.findAll()).hasSize(1);
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| test slice(測試切片) | Spring Boot 只啟動應用程式一部分功能來測試,而不是整個應用程式都啟動 |
| @DataJpaTest | 一種 test slice 註解,只啟動跟資料庫存取(JPA/Repository)相關的部分 |
| in-memory database(記憶體資料庫) | 測試用的暫時資料庫(常見是 H2),資料存在記憶體裡,關掉就消失 |
| rollback(回滾) | 把資料庫的改動復原,回到測試前的狀態 |
| Repository | 負責跟資料庫溝通(存/查/刪資料)的介面 |

### 一句話帶走

@DataJpaTest 只啟動「資料庫那一層」,測試跑得快,而且每次測完資料都會自動清空重來。
