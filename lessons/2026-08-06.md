## 路徑參數、查詢參數、@RequestBody · 第 2 步

### 概念：@RequestParam（查詢參數）

- @PathVariable（昨天）：抓網址路徑裡固定占位的一段，例如 /users/{id}，決定「要哪一個」資源。
- @RequestParam（今天）：抓網址 `?` 後面 key=value 形式的查詢參數，多個用 `&` 分隔，例如 /users?page=2&size=10。用來表示「可有可無的篩選/選項」。
- 沒帶查詢參數時，可以用 defaultValue 給預設值，避免程式出錯。

### 程式碼

```java
@GetMapping("/users")
public String listUsers(
        @RequestParam(defaultValue = "1") int page,
        @RequestParam(defaultValue = "10") int size) {
    return "第 " + page + " 頁，每頁 " + size + " 筆";
}

// /users                -> 第 1 頁，每頁 10 筆
// /users?page=2         -> 第 2 頁，每頁 10 筆
// /users?page=2&size=20 -> 第 2 頁，每頁 20 筆
```

### 術語表

| 術語 | 定義 |
|---|---|
| Query Parameter 查詢參數 | 網址 `?` 之後 key=value 形式的參數，多個用 `&` 隔開 |
| @RequestParam | 貼在方法參數上，讓 Spring 從查詢參數抓值 |
| defaultValue | 沒帶該查詢參數時使用的預設值 |
