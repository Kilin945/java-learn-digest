## Bean Validation：@Valid 與 @NotNull · 第 3 步

### 概念：@Size 限制長度範圍

前兩天教的 `@NotNull`、`@NotBlank` 都只回答「有沒有內容」，沒管內容「多長才合理」。`@Size` 用 `min`／`max` 屬性幫欄位設定長度上下限，超出範圍就會被 Bean Validation 擋下、回 400 Bad Request。

可以跟 `@NotBlank` 疊在同一個欄位上使用，兩個規則互不衝突：

```java
public class UserDto {

    @NotBlank
    @Size(min = 3, max = 20, message = "使用者名稱長度需在 3~20 字之間")
    private String username;
}
```

`message` 屬性可以自訂驗證失敗時的說明文字，不設定就會用內建的預設英文訊息（例如 `size must be between 3 and 20`）。

### 術語表

| 術語 | 定義 |
|---|---|
| `@Size` | 長度驗證註解，檢查字串（或清單）長度／元素數量是否落在 min~max 範圍內 |
| `min` / `max` | @Size 用來設定合法長度範圍上下限的參數，可只設一個或同時設定 |
| `message` | 自訂驗證失敗時回傳的錯誤說明文字，未設定則用預設英文訊息 |
