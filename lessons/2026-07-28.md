## 內嵌 Tomcat 與 main() 啟動流程 · 第 1 步

### 概念
傳統 Java Web 開發要先安裝並設定一台獨立的 Tomcat 伺服器，再把應用程式打包成 WAR 檔丟進去部署。Spring Boot 改用「內嵌 Tomcat（embedded Tomcat）」：把 Tomcat 的程式碼直接打包進應用程式的 jar 檔裡，執行 `java -jar app.jar` 時，程式的 `main()` 方法會呼叫 `SpringApplication.run(...)`，這一步就會自動啟動內嵌的 Tomcat，預設監聽 8080 port，不需要事先安裝任何外部伺服器。

### 程式碼
```java
@SpringBootApplication
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}
```
執行後主控台會出現類似 `Tomcat started on port 8080` 的訊息，代表內嵌伺服器已啟動完成。

### 術語表
| 術語 | 定義 |
|---|---|
| Tomcat | 負責接收瀏覽器請求、轉交給你的程式碼處理的伺服器程式（servlet container） |
| Embedded（內嵌） | 把伺服器程式碼打包進應用程式裡，不需另外安裝 |
| main() | Java 程式的進入點，執行時第一個被呼叫的方法 |
| SpringApplication.run() | 啟動整個 Spring Boot 框架與內嵌伺服器的靜態方法 |
| Port（埠號） | 伺服器對外開放的門牌號碼，瀏覽器需指定此號碼才能連線 |
