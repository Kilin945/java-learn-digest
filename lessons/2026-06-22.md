## @Configuration 與 @Bean：手動定義 Bean · 第 3 步

### 概念：@Bean Naming & @Primary

每個 `@Bean` 都有一個**名稱（name）**，預設等於方法名，可用 `@Bean("xxx")` 自訂。

當容器中存在**多個相同型別的 Bean** 時，Spring 注入時找不到唯一候選，會拋出 `NoUniqueBeanDefinitionException`。

解法：在「希望作為預設」的 Bean 方法上加 `@Primary`，Spring 沒有指定名稱時就選它。

### 程式碼範例

```java
@Configuration
public class CacheConfig {

    @Bean
    @Primary                          // 首選：型別衝突時預設用這個
    public CacheService devCache() {
        return new InMemoryCacheService();
    }

    @Bean("redisCache")               // 自訂名稱；非首選
    public CacheService redisCache() {
        return new RedisCacheService();
    }
}

@Service
public class OrderService {
    public OrderService(CacheService cache) {
        // Spring 自動注入 devCache（因為它是 @Primary）
    }
}
```

### 術語表

| 術語 | 說明 |
|------|------|
| `@Bean(name)` | 自訂 Bean 名稱，預設 = 方法名 |
| `@Primary` | 同型別多 Bean 時的預設首選 |
| `NoUniqueBeanDefinitionException` | Spring 找到多個同型 Bean 且無 @Primary 可決勝時拋出的例外 |

### 關鍵比喻

劇組有兩位男主角候選人，導演直接喊「男主角上場！」兩人都愣住。`@Primary` 就是事先貼在其中一人身上的首選標籤，導演不指名時就找他。
