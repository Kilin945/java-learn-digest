## 設定外部化與機密管理 · 第 1 步

### 概念：Externalized Configuration with @Value

把「會變的設定」（例如訊息文字、網址、開關）搬出 Java 程式碼，放進 Spring Boot 內建的設定檔 `application.properties`，執行時再讀取，這樣換設定不用改 code、不用重新編譯。

### 程式碼對照

```java
// ❌ 舊寫法：訊息寫死在程式碼裡
@RestController
public class GreetingController {

    @GetMapping("/greeting")
    public String greeting() {
        return "Hello, 這是寫死的訪客訊息！";
    }
}
```

```properties
# src/main/resources/application.properties
app.greeting=Hello, 這是從設定檔讀出來的訊息！
```

```java
// ✅ 新寫法：用 @Value 從 application.properties 讀值
@RestController
public class GreetingController {

    @Value("${app.greeting}")
    private String greeting;

    @GetMapping("/greeting")
    public String greeting() {
        return greeting;
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| Hardcode（寫死） | 設定值直接打在程式碼裡，要改就得改 code、重新編譯 |
| Externalized Configuration（設定外部化） | 把設定值搬到程式碼外的檔案，執行時才讀取 |
| application.properties（設定檔） | Spring Boot 內建的「鍵=值」純文字設定檔，位於 src/main/resources |
| Property（屬性/設定值） | 設定檔裡一行「key=value」的資料 |
| @Value（註解） | 貼在變數上的標記，告訴 Spring 把某個 property 填進這個變數 |
| Placeholder `${...}`（佔位符） | 先留個位置，實際值由設定檔對應的 key 填入 |
