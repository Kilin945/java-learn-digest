## @Configuration 與 @Bean：手動定義 Bean · 第 2 步

### 概念：@Bean Parameter Injection

當一個 @Bean 需要用到另一個 @Bean（即存在「依賴」關係），只需把所需 Bean 的型別**宣告為 @Bean 方法的參數**，Spring 自動從容器中找到並注入對應的 Bean。

### 程式碼範例

```java
@Configuration
public class AppConfig {

    @Bean
    public DataSource dataSource() {         // Bean①：第三方類別
        HikariDataSource ds = new HikariDataSource();
        ds.setJdbcUrl("jdbc:h2:mem:testdb");
        return ds;
    }

    @Bean
    public UserDao userDao(DataSource ds) {  // 參數 = 我需要 DataSource
        return new UserDao(ds);              // Spring 自動把 Bean① 傳進來
    }
}
```

### 術語表

| 術語 | 白話定義 |
|------|----------|
| Dependency（依賴） | A 物件需要 B 物件才能運作，就說「A 依賴 B」 |
| Parameter Injection（參數注入） | 在 @Bean 方法參數中宣告所需型別，Spring 自動注入，不需手動 new |

### 今日重點

需要哪個 Bean，就把型別寫在 @Bean 方法的參數裡，Spring 自動注入，不用自己 new。
