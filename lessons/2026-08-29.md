## Entity 對應：@Entity / @Id / 關聯 · 第 4 步

### 概念：@ManyToOne 多對一關聯

真實世界的資料常常互相關聯，例如很多張訂單（Order）都屬於同一個顧客（Customer），就像很多學生屬於同一個班級。在 JPA（Jakarta Persistence API）裡，這種「多筆指向同一筆」的關係用 `@ManyToOne` 標記在「多」的那一方，並搭配 `@JoinColumn` 指定資料庫裡實際存放外鍵（foreign key，指向另一張表主鍵的欄位）的欄位名稱。

### 程式碼

```java
@Entity
public class Customer {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;
}

@Entity
public class Order {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String item;

    @ManyToOne
    @JoinColumn(name = "customer_id")
    private Customer customer;  // 這張訂單屬於哪個顧客
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| @ManyToOne（多對一） | 標記「很多筆這個 Entity 會指向同一筆另一個 Entity」的欄位 |
| @JoinColumn（關聯欄位設定） | 指定資料庫裡用來存放外鍵的實際欄位名稱 |
| foreign key（外鍵） | 資料表裡存放另一張表主鍵值的欄位，用來記錄兩筆資料之間的關聯 |
