## 設定外部化與機密管理 · 第 4 步

### 概念：@ConfigurationProperties 打包設定

當同一類設定值變多（例如資料庫的 host、port、password），一個一個寫 `@Value` 會很難維護。
`@ConfigurationProperties` 讓你把某個前綴（prefix）開頭的所有設定值，自動綁定到一個 Java 類別的同名欄位上，一次拿到全部設定，且是型別安全的（編譯期就能檢查型別，例如 port 若不是數字啟動時就報錯）。

密碼欄位的來源不變：仍然交給環境變數覆蓋，不寫進設定檔或 profile 檔案。

### 程式碼

```java
// 之前：設定一多，@Value 就會愈疊愈多
@Value("${db.host}")     private String dbHost;
@Value("${db.port}")     private int dbPort;
@Value("${db.password}") private String dbPassword;

// 今天：改成一個「設定包裹」類別
@ConfigurationProperties(prefix = "db")
public class DbProperties {
    private String host;
    private int port;
    private String password;
    // getter / setter 省略
}

@SpringBootApplication
@EnableConfigurationProperties(DbProperties.class)
public class MyApp { ... }

@Service
public class DbConnector {
    private final DbProperties props;
    public DbConnector(DbProperties props) { this.props = props; }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| @ConfigurationProperties | 把某前綴開頭的設定值自動綁定到類別同名欄位 |
| prefix | 設定 key 共同的開頭字，例如 `db.host` 的前綴是 `db` |
| @EnableConfigurationProperties | 啟用某個設定包裹類別，交給 Spring 管理 |
| 型別安全（type-safe） | 欄位型別在啟動時就會被檢查，型別不符直接報錯 |
