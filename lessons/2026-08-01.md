## @RestController 與 @RequestMapping 家族 · 第 1 步

### 概念：@RestController 是什麼

把 Spring 裡的類別（class）想成餐廳的兩種櫃檯：

- **傳統 Controller**：像內用櫃檯，回傳一個 View（樣板），伺服器把資料套進網頁模板、組成完整 HTML 頁面再送出去。
- **@RestController**：像外帶窗口，直接把資料（文字、JSON）裝進 response body（回應本文）送回去，不經過任何排版模板。

加上 `@RestController` 這個 annotation（註解／標籤）之後，這個類別裡的方法在被 HTTP 請求呼叫時，回傳值會直接變成回應內容送出去。

### 程式碼

```java
@RestController          // 這個類別變成「外帶窗口」
public class HelloController {

    @GetMapping("/hello")  // 下一步細講：負責監聽哪個網址
    public String sayHello() {
        return "Hello, Spring Boot!";  // 直接送回去，不排版
    }
}
```

打開 `http://localhost:8080/hello`，畫面上會直接顯示 `Hello, Spring Boot!` 這行字，沒有任何 HTML 排版。

### 術語表

| 術語 | 定義 |
|---|---|
| Annotation（註解／標籤） | 貼在程式碼上、以 @ 開頭的標記，告訴 Spring 這段程式碼的用途。 |
| HTTP 請求 | 瀏覽器或 App 向伺服器「要求什麼」的動作。 |
| View（樣板） | 傳統網頁用的排版模板檔案。 |
| Response Body（回應本文） | 伺服器回話時實際裝著資料的內容。 |
