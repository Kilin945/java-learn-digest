## 路徑參數、查詢參數、@RequestBody · 第 1 步

### 概念：@PathVariable — 抓出網址裡「會變動」的那一段

昨天學到路徑是 class 前綴（@RequestMapping）+ method 路徑（@GetMapping 等）拼起來的固定字串。但很多網址裡有「會變動」的部分，例如查第幾號使用者：`/users/3`、`/users/8`，這個數字每次不同，不可能寫死。

Spring Boot 的做法：

1. 在路徑裡用大括號寫一個**佔位符**（placeholder），組成**路徑範本（path template）**，例如 `/users/{id}`。
2. 在方法參數前貼上 **@PathVariable** 標籤（annotation），且參數名跟 `{id}` 對上，Spring 就會自動把網址裡實際填的值抓進來。

### 程式碼

```java
@RestController
@RequestMapping("/users")
public class UserController {

    @GetMapping("/{id}")
    public String getUser(@PathVariable Long id) {
        return "查詢的使用者 id 是：" + id;
    }
}

// GET /users/3  →  查詢的使用者 id 是：3
// GET /users/8  →  查詢的使用者 id 是：8
```

### 術語表

| 術語 | 定義 |
|---|---|
| Path template（路徑範本） | 路徑裡用 `{}` 寫佔位符的寫法，代表這格之後會被實際值取代 |
| @PathVariable（路徑變數標籤） | 貼在方法參數前，告訴 Spring 把路徑範本裡對應名字的值塞進這個參數 |
| Annotation（標籤/註解） | Java 裡 `@` 開頭的標記，是給框架看的指示，不是邏輯本身 |

### 一句話帶走

網址用 `{名字}` 占位，參數用 `@PathVariable` 接住，名字對上值就自動注入。
