## @Value 與 application.properties 讀設定 · 第 1 步

### 概念
- **application.properties（應用程式設定檔）**：Spring Boot 專案中集中放設定值的檔案，格式為 `key=value`，預設路徑為 `src/main/resources/application.properties`。
- **@Value**：貼在欄位上的 annotation（注解），用 `${key}` 語法告訴 Spring 去設定檔找對應 key 的值並填入該欄位。
- 目的：避免把會變動的設定值 hardcode（寫死）在程式碼裡，改設定不用重新編譯程式。

### 範例程式碼
```properties
# application.properties
app.greeting=Hello from properties!
```

```java
// GreetingService.java
@Component
public class GreetingService {

    @Value("${app.greeting}")
    private String greeting;

    public String getGreeting() {
        return greeting;
    }
}
```

### 術語表
| 術語 | 定義 |
|---|---|
| application.properties | Spring Boot 專案的設定檔，key=value 格式，預設在 src/main/resources 下 |
| @Value | 注解，用 ${key} 語法把設定檔的值注入到欄位 |
| Hardcode（寫死） | 把會變動的值直接打在程式碼裡，難以維護 |

### 昨日複習（@Primary / @Qualifier 主題收尾）
1. 有 @Primary 但注入點沒寫 @Qualifier → 選 @Primary 標記的實作。
2. @Primary 與 @Qualifier 同時存在 → @Qualifier 優先。
3. NoUniqueBeanDefinitionException → 同一介面有多個候選 Bean，Spring 無法判斷該注入哪一個。
