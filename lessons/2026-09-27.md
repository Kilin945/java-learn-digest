## 設定外部化與機密管理 · 第 3 步

### 概念：Spring Profiles

同一支程式在不同環境（開發／正式）需要不同的設定值（例如資料庫網址）。Spring Boot 用 **profile-specific 檔案**解決這件事：

- `application.properties`：共用的預設值
- `application-{profile名稱}.properties`：特定環境才用的值，會覆蓋共用檔裡同名的 key
- 啟動時用 `--spring.profiles.active={profile名稱}` 指定要吃哪一份

比喻：Profile 就像手機的「飛航模式／一般模式」切換鈕——程式碼本體不變，但切換模式後整組設定跟著換。

### 程式碼

```properties
# application.properties（共用預設值）
app.name=my-service

# application-dev.properties（本機開發用）
db.url=jdbc:mysql://localhost:3306/mydb

# application-prod.properties（正式機用）
db.url=jdbc:mysql://prod-host:3306/mydb
```

```bash
# 啟動時指定要用哪個 profile
java -jar app.jar --spring.profiles.active=dev
```

```java
// Java 端完全不用改
@Value("${db.url}")
private String dbUrl;
```

**重要邊界**：Profile 負責處理「因環境而異但不是機密」的設定（網址、埠號、開關）。密碼等機密仍然交給環境變數（見第 2 步），不要寫進任何一份 profile 檔案，因為那些檔案通常還是會進 git。

### 術語表

| 術語 | 定義 |
|---|---|
| Profile（設定檔模式） | 一組屬於特定環境的設定值集合，用檔名 `application-{名稱}.properties` 區分 |
| active profile（啟用的模式） | 啟動時指定的、這次要用的 profile |
| 覆蓋（override） | 同一個 key 在共用檔跟 profile 檔都出現時，以 profile 檔的值為主 |
