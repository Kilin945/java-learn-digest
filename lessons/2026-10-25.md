## B9 · deadlock 是什麼？怎麼避免、怎麼查？

### 答案
deadlock（死結）是兩條執行緒各自握著對方要的鎖，互相等，誰都不放手。避免：所有人照同一個固定順序拿鎖；或拿鎖加等待逾時。查：抓 thread dump，JVM 會標出 `Found one Java-level deadlock` 與卡住的兩把鎖。

你的錨點：OOM 調查時抓過 thread dump（同一個工具）；叢集節點不同步、快取廣播清除是共享狀態爭用的場景，多處各自上鎖時有死結風險。

### 第 1 輪（比喻）：鎖不是用完就放，怎麼會互等？
單把鎖不會死結。問題在一條執行緒握著第一把去等第二把。比喻：窄橋兩端的人各走到橋中間，都等對方先退。A 握鎖 1 等鎖 2，B 握鎖 2 等鎖 1。

### 第 2 輪（程式碼）：轉帳例子
```java
// ❌ 壞：順序看誰轉給誰
void transfer(Account from, Account to, int amt) {
    synchronized (from) {
        synchronized (to) {
            from.withdraw(amt);
            to.deposit(amt);
        }
    }
}

// ✅ 好：永遠先鎖 id 小的
void transfer(Account from, Account to, int amt) {
    Account first  = from.id() < to.id() ? from : to;
    Account second = first == from ? to : from;
    synchronized (first) {
        synchronized (second) {
            from.withdraw(amt);
            to.deposit(amt);
        }
    }
}
```

### 第 3 輪（圖解）：為什麼順序一致就不會死結？
死結一定繞成一圈。規定只能由小號往大號拿，每條執行緒手上最大的號碼只會變大，等的永遠是更大的號碼，要繞回來得去等更小的，規則不允許，所以圈畫不出來。

### 第 4 輪（反例）：順序排不出來怎麼辦？
用逾時。`synchronized` 只能無限等；`ReentrantLock.tryLock(時間)` 等不到回傳 false，放掉手上的鎖後重試或報錯。
```java
if (lock1.tryLock(1, TimeUnit.SECONDS)) {
    try {
        if (lock2.tryLock(1, TimeUnit.SECONDS)) {
            try { /* 做事 */ } finally { lock2.unlock(); }
        } else {
            // 放掉第一把，稍後重試或回報失敗
        }
    } finally { lock1.unlock(); }
}
```
代價：要自己處理拿不到的後續，且只是不卡死，沒消除互等的根源。

### 第 5 輪（錨點）：怎麼確定是死結，不是慢？
步驟：`jps` 找 pid → `jstack <pid>`（或 `kill -3 <pid>`）→ 搜尋 `Found one Java-level deadlock`。
```
Found one Java-level deadlock:
"Thread-1":
  waiting to lock monitor ... which is held by "Thread-0"
"Thread-0":
  waiting to lock monitor ... which is held by "Thread-1"
```
互相等成一圈就是死結。只是慢的話 dump 裡沒有這一段。

### 第 6 輪（面試追問）：四個必要條件？打破一個夠嗎？
互斥、持有並等待、不可搶奪、循環等待，四個同時成立才死結，打破任一個就夠。實務最好打破循環等待（固定上鎖順序）；其他三個做不到或代價太大。

### 術語表
| 術語 | 中文 | 定義 |
|---|---|---|
| deadlock | 死結 | 執行緒互等對方的鎖，全部卡住 |
| lock | 鎖 | 同一時間只讓一條執行緒進入的機制 |
| thread dump | 執行緒快照 | 某刻所有執行緒狀態與堆疊 |
| tryLock | 嘗試取鎖 | 可設等待時間，等不到回傳 false |
| circular wait | 循環等待 | 等待關係繞成一圈，固定順序可打破 |
