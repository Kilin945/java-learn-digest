## @DataJpaTest 等測試切片 · 第 2 步

### 概念
- @DataJpaTest 只會啟動跟資料庫相關的 Bean，資料庫是空的，要測查詢功能得先塞資料。
- 用 TestEntityManager 手動存入一筆測試資料，再呼叫 Repository 方法驗證能不能查到，這是「測資料庫功能」最基本的寫法。
- 測試流程遵循 AAA 模式：Arrange（準備）→ Act（執行）→ Assert（驗證）。

### 程式碼
```java
@DataJpaTest
class MemberRepositoryTest {

    @Autowired
    private TestEntityManager entityManager;

    @Autowired
    private MemberRepository memberRepository;

    @Test
    void findByEmail_shouldReturnMember() {
        // Arrange
        Member member = new Member("kilin@example.com", "Kilin");
        entityManager.persistAndFlush(member);

        // Act
        Optional<Member> found = memberRepository.findByEmail("kilin@example.com");

        // Assert
        assertThat(found).isPresent();
        assertThat(found.get().getName()).isEqualTo("Kilin");
    }
}
```

### 術語表
- **TestEntityManager**（測試實體管理員）：測試專用工具，可直接把物件存進測試資料庫。
- **persistAndFlush**（存入並寫入）：存資料並立即真正寫入，之後查詢才找得到。
- **Repository**（資料庫存取介面）：負責跟資料庫溝通的元件，本篇測試的對象。
- **AAA 模式**（準備-執行-驗證）：Arrange / Act / Assert 三段式測試結構。
- **assertThat**（斷言）：AssertJ 套件提供的檢查工具，用來驗證結果是否符合預期。
