## Bean 的 scope 與生命週期 · 第 3 步

### @PostConstruct & @PreDestroy — Bean 的生命週期鉤子

Spring 建立 Bean 的順序：**new 物件 → 注入（@Autowired）→ 呼叫 @PostConstruct**。

- **@PostConstruct**：注入完成後自動執行一次，適合初始化資源（如預熱快取、建立連線）
- **@PreDestroy**：容器關閉前自動執行，適合釋放資源（如關閉連線、清除暫存）

⚠️ @PreDestroy 只對 **singleton** Bean 有效；prototype Bean 由呼叫端自行管理生命週期。

### 程式碼範例

```java
@Component
public class CacheService {

    @PostConstruct
    public void init() {
        // 注入完成後自動執行，適合「初始化資源」
        System.out.println("CacheService 上線：預熱快取");
    }

    @PreDestroy
    public void cleanup() {
        // 容器關閉前自動執行，適合「釋放資源」
        System.out.println("CacheService 下線：清除快取");
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|------|------|------|
| @PostConstruct | 建構後 | Bean 建立且注入完成後自動呼叫，適合初始化 |
| @PreDestroy | 銷毀前 | 容器關閉前自動呼叫，僅 singleton 有效 |
| Lifecycle callback | 生命週期回呼 | 框架在特定節點自動呼叫的方法 |

### 一句話重點

@PostConstruct 是服務生上班後的備料動作，@PreDestroy 是下班前的打烊清理，但 Prototype Bean 離職自己善後，Spring 不管。
