## Starter 依賴：spring-boot-starter-web 幫你帶了什麼 · 第 4 步

### 概念：Jackson 自動把物件變 JSON

spring-boot-starter-web 裡除了內建 Tomcat 伺服器、Spring MVC（DispatcherServlet + @RestController + @GetMapping），還內建了 **Jackson** 函式庫。當你的 Controller 方法回傳一個 Java 物件時，Jackson 會自動把它轉換成 JSON 格式的文字，直接回傳給前端，完全不需要自己手動轉換。

### 範例程式碼

```java
@RestController
public class HelloController {

    @GetMapping("/user")
    public User getUser() {
        return new User("Kilin", 30);
    }
}

record User(String name, int age) {}

// 瀏覽器打開 /user 會看到：
// {"name":"Kilin","age":30}
```

### 本主題總結

spring-boot-starter-web = 內建 Tomcat 伺服器 + Spring MVC 轉接（DispatcherServlet / @RestController / @GetMapping）+ Jackson 自動轉 JSON，三樣東西一次到位。

### 術語表

| 術語 | 中文 | 定義 |
|------|------|------|
| Jackson | 翻譯函式庫 | Spring Boot 內建的工具，自動把 Java 物件和 JSON 文字互相轉換 |
| JSON | 資料交換格式 | 前後端都看得懂的文字格式，長得像 `{"name":"Kilin"}` |
| Serialization | 序列化 | 把程式裡的物件轉換成可以傳輸的文字格式的過程 |
