## Spring Data JPA 與 Repository 介面 · 第 1 步

### 概念
- **ORM（物件關聯對映）**：讓 Java 物件跟資料庫表格互相翻譯的技術，不用自己寫 SQL 就能操作資料。
- **JPA（Java 持久化 API）**：Java 官方定義「物件怎麼存進資料庫」的規範。
- **Entity（實體類別）**：用 `@Entity` 標記的 class，對應資料庫裡的一張表；用 `@Id` 標記主鍵欄位。
- **Repository（儲存庫介面）**：只要定義一個 interface 繼承 `JpaRepository<Entity型別, 主鍵型別>`，Spring Data JPA 就會在背後自動實作出增刪改查的方法，完全不用自己寫實作類別。

### 程式碼
```java
// Entity：對應資料庫的 users 資料表
@Entity
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String name;
    // getter/setter 省略
}

// Repository：只要繼承它，CRUD 方法就自動生成好了！
public interface UserRepository extends JpaRepository<User, Long> {
}
```

### 術語表
| 術語 | 中文 | 定義 |
|---|---|---|
| JPA | Java 持久化 API | Java 官方定義物件持久化的規範 |
| ORM | 物件關聯對映 | Java 物件與資料表互相轉換的技術 |
| Entity | 實體類別 | 對應資料表的 class，用 `@Entity` 標記 |
| Repository | 儲存庫介面 | 只定義資料操作方法、由框架自動實作的介面 |
