## Profiles：dev / prod 用不同設定 · 第 1 步

### 概念

同一支程式，開發環境（dev）和正式環境（prod）常常需要不同設定（例如資料庫網址）。若每次上線都手動改設定值，容易出錯又麻煩。

Spring Boot 提供 **Profile**（環境設定檔／情境設定）機制：為不同情境各自準備一份設定檔，Spring 會依目前啟用的情境自動載入對應設定，程式碼不需要修改。

命名規則：

- `application.properties`：預設、所有情境都會先讀取
- `application-dev.properties`：只在 dev 情境生效
- `application-prod.properties`：只在 prod 情境生效

本步只涵蓋「檔案有哪些、怎麼命名」，尚未涉及如何切換啟用哪個 Profile（留待下一步）。

### 程式碼

```properties
# application.properties（大家都會讀到）
app.name=MyShop

# application-dev.properties（只有 dev 情境會讀到）
db.url=jdbc:mysql://localhost:3306/myshop_dev

# application-prod.properties（只有 prod 情境會讀到）
db.url=jdbc:mysql://prod-server:3306/myshop
```

### 術語表

| 術語 | 定義 |
|---|---|
| Profile | Spring Boot 用來區分不同執行環境的機制，讓同一支程式套用不同設定 |
| application.properties | 不分情境都會被載入的基礎設定檔 |
| application-{profile}.properties | 只有對應情境啟用時才會載入的設定檔 |
| dev / prod | 開發環境（development）／正式環境（production）|
