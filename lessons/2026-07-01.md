## Bean 的 scope 與生命週期 · 第 4 步

### Prototype Bean in Singleton — The Hidden Trap

**核心概念**

Singleton Bean 只在容器啟動時建立一次，@Autowired 注入的 Prototype Bean 也只注入一次，後續不會自動刷新。要每次取得新實例，必須直接向 ApplicationContext 取用。

### ❌ 陷阱寫法

```java
@Component
@Scope("prototype")
public class Counter {
    private int count = 0;
    public void increment() { count++; }
    public int getCount()   { return count; }
}

@Component  // 預設 singleton
public class OrderService {
    @Autowired
    private Counter counter;  // 只注入一次！

    public void process() {
        counter.increment();
        // 呼叫三次：預期 1,1,1，實際 1,2,3
        System.out.println("count = " + counter.getCount());
    }
}
```

### ✅ 正確寫法

```java
@Component
public class OrderService {
    @Autowired
    private ApplicationContext ctx;  // 注入容器本身

    public void process() {
        Counter counter = ctx.getBean(Counter.class);  // 每次都是新的
        counter.increment();
        System.out.println("count = " + counter.getCount());
    }
}
// 三次 process() 輸出確實是 1,1,1 ✓
```

### 術語表

| 術語 | 中文 | 說明 |
|------|------|------|
| ApplicationContext | 應用程式上下文（容器） | Spring 核心容器，可用 getBean() 手動取得任意 Bean |
| getBean() | 從容器取 Bean | 每次呼叫對 Prototype Bean 都回傳全新實例 |
| Injection Trap | 注入陷阱 | Singleton 只初始化一次，@Autowired 的 Prototype 不會自動刷新 |
