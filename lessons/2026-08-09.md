## DTO 與 entity 為什麼要分開 · 第 2 步

### What is a DTO?

DTO（Data Transfer Object，資料傳輸物件）是**自己寫的一個普通類別**，跟資料庫表格沒有關係，只用來裝「要傳給前端」的資料。

比喻：Entity 是員工的完整人事檔案（薪水、身分證號都在裡面）；DTO 是名片，只印出想讓別人看到的資訊。

```java
// Entity：對應資料庫表格，欄位齊全（含機密資料）
public class User {
    private Long id;
    private String name;
    private String email;
    private String password;   // 機密！不能外流
    private String idNumber;   // 身分證號，也不能外流
}

// DTO：你自己寫的，只放要給前端看的欄位
public class UserDto {
    private Long id;
    private String name;
    private String email;
    // 沒有 password、沒有 idNumber
}
```

**一句話帶走**：DTO 就是一張只印必要資訊的名片，你自己決定要印什麼。

### 術語表

| 術語 | 定義 |
|---|---|
| DTO | Data Transfer Object，自己寫的類別，只裝要傳給前端的資料，跟資料庫表格無關 |
| Entity | 對應資料庫表格的類別，欄位齊全，通常含機密資料 |
| field | class 裡用來存資料的變數，例如 name、email |
