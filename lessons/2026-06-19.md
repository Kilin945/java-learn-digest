## 建構子注入 vs 欄位注入 vs setter 注入 · 第 3 步

### 概念：Setter Injection

Setter Injection 是把 `@Autowired` 標在 setter 方法（`setXxx()`）上，讓 Spring 先建好物件後才呼叫 setter 方法注入依賴。欄位沒有 `final`，依賴可在物件生命週期中被替換，彈性高但不可變性低。

**主要使用場景：**
- **可選依賴（optional dependency）**：依賴有就用、沒有也能運作，搭配 `required = false`，注入前做 null 檢查。
- **循環依賴（circular dependency）**：A 需要 B、B 需要 A，建構子注入啟動失敗，setter 注入可繞開。

### 程式碼範例

```java
@Service
public class OrderService {

    // 沒有 final，物件建立後才注入
    private DiscountService discountService;

    @Autowired(required = false)
    public void setDiscountService(DiscountService discountService) {
        this.discountService = discountService;
    }

    public int calcPrice(int price) {
        if (discountService != null) {
            return discountService.apply(price);
        }
        return price;
    }
}
```

### 三種注入方式比較表

| 比較項目 | 欄位注入 | 建構子注入 ✅ | Setter 注入 |
|---|:---:|:---:|:---:|
| 可標 `final` | ❌ | ✅ | ❌ |
| 易於單元測試 | ❌ | ✅ | △ |
| 支援可選依賴 | ❌ | ❌ | ✅ |
| 解決循環依賴 | ✅ | ❌ | ✅ |
| Spring 官方推薦 | ❌ 不推 | ✅ 首選 | △ 特定場景 |

### 術語表

| 術語 | 中文 | 白話定義 |
|---|---|---|
| Setter Injection | setter 注入 | 把 @Autowired 標在 setXxx() 方法上，建好物件後才注入 |
| optional dependency | 可選依賴 | 有注入就用、沒有也能運作；用 @Autowired(required=false) 標記 |
| circular dependency | 循環依賴 | A 需要 B、B 需要 A，形成互相等待的圈；建構子注入會啟動失敗 |

### 結論

> **預設用建構子注入；只有「可選依賴」或「循環依賴」才改用 setter 注入；欄位注入能不用就不用。**
