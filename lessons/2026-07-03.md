## @Autowired、@Qualifier 與多個候選 Bean 的解析 · 第 1 步

### 概念
- **Bean**：被 Spring 容器管理、隨時可取用的物件。
- **Dependency（依賴）**：A 物件需要 B 物件才能運作，這種關係。
- **Dependency Injection（依賴注入，DI）**：容器主動把需要的 Bean 送進你的類別，而不是自己 `new`。
- **@Autowired**：標在建構子（或欄位/方法）上，告訴 Spring「請自動注入這個型別的 Bean」。
- 目前情境：`NotificationService` 介面只有一個實作 `EmailNotificationService`，Spring 可以毫無疑問地決定要注入哪一個 Bean。
- 下一步預告：當出現第二個實作（例如簡訊通知）時，Spring 會不知道該注入哪一個，這時就需要 `@Qualifier` 出場。

### 程式碼
```java
public interface NotificationService {
    void send(String message);
}

@Service
public class EmailNotificationService implements NotificationService {
    @Override
    public void send(String message) {
        System.out.println("寄送 Email 通知: " + message);
    }
}

@Service
public class OrderService {

    private final NotificationService notificationService;

    @Autowired
    public OrderService(NotificationService notificationService) {
        this.notificationService = notificationService;
    }

    public void placeOrder() {
        notificationService.send("您的訂單已成立！");
    }
}
```

### 術語表
| 術語 | 定義 |
|---|---|
| Bean | 被 Spring 容器管理、隨時可拿來用的物件 |
| Dependency（依賴） | 一個物件需要另一個物件才能運作的關係 |
| Dependency Injection（依賴注入） | 容器主動把依賴送進類別，而非自行 `new` |
| @Autowired | 標記需要自動注入 Bean 的位置 |
| Container（容器） | 負責建立、管理並注入 Bean 的 Spring 核心機制 |
