## MockMvc 測 Controller · 第 1 步

### 概念
- 昨天的 `@SpringBootTest` 會把整個 Spring 應用程式都組裝、啟動起來測試，完整但慢。
- `MockMvc` 是一個假的 HTTP 客戶端，可以模擬對 Controller 發出請求（例如 GET /hello），並檢查回應內容，全程不需要真的啟動伺服器監聽 port。
- `@WebMvcTest` 是一種 slice test（切片測試），只載入網頁層（Controller）相關的元件，比 `@SpringBootTest` 輕量快速許多。

### 程式碼
```java
// Controller
@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello, Spring Boot!";
    }
}

// 測試
@WebMvcTest(HelloController.class)
class HelloControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Test
    void hello_shouldReturnGreeting() throws Exception {
        mockMvc.perform(get("/hello"))
               .andExpect(status().isOk())
               .andExpect(content().string("Hello, Spring Boot!"));
    }
}
```

### 術語表
| 術語 | 定義 |
|---|---|
| MockMvc | 假的 HTTP 客戶端，模擬瀏覽器發請求給 Controller 並檢查回應，不需真的啟動伺服器 |
| @WebMvcTest | 網頁層切片測試（slice test），只載入 Controller 相關的元件 |
| perform() | 用 MockMvc 送出一個模擬的 HTTP 請求 |
| andExpect() | 檢查回應是否符合預期（狀態碼、內容等） |
| status().isOk() | 代表 HTTP 200，請求成功處理的狀態碼 |
