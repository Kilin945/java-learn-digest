## Profiles：dev / prod 用不同設定 · 第 2 步

### 概念：Activating a Profile（啟用 Profile）

光是準備好 `application-dev.properties` 和 `application-prod.properties` 還不夠，必須明確告訴 Spring Boot「現在要用哪一套」，這個開關就是 `spring.profiles.active`。

寫在共用的 `application.properties` 裡：

```properties
# application.properties
spring.profiles.active=dev
```

程式啟動時會把 `application.properties`（共用）與 `application-dev.properties`（dev 專屬）疊加使用，若兩邊有相同設定項目，**dev 專屬設定會蓋過共用設定**。

也可以在啟動時用命令列參數切換，不用改程式碼，常用於正式環境部署：

```bash
java -jar app.jar --spring.profiles.active=prod
```

### 術語表

| 術語 | 定義 |
|---|---|
| spring.profiles.active | 告訴 Spring Boot 現在要套用哪一個 Profile 的設定項目 |
| command-line argument（命令列參數） | 啟動程式時附加的參數，例如 `--spring.profiles.active=prod`，可不改程式碼切換設定 |
| 疊加（override，設定覆蓋） | Profile 專屬設定與共用設定同名時，專屬設定會蓋過共用設定的值 |
