## @Configuration 與 @Bean：手動定義 Bean · 第 6 步

### 概念：Bean Lifecycle Callbacks

Bean 生命週期有四個關鍵時間點：**建立 → 依賴注入 → 使用 → 銷毀**。Spring 提供兩個標注讓你在頭尾各掛一個鉤子：

- **@PostConstruct**（後建構）：Bean 建立且所有依賴注入完成後，立即自動執行。適合初始化：預熱快取、建立連線池、載入設定。
- **@PreDestroy**（前銷毀）：容器關閉、Bean 即將銷毀前，自動執行。適合清理：關閉連線、清空快取、釋放資源。

> ⚠️ prototype Bean **不觸發** @PreDestroy，清理責任由呼叫端自行處理。

### 用法 A：@PostConstruct / @PreDestroy（最常用）

```java
import jakarta.annotation.PostConstruct;
import jakarta.annotation.PreDestroy;

@Component
public class CacheService {

    @PostConstruct
    public void init() {
        System.out.println("✅ 快取預熱中…");
    }

    @PreDestroy
    public void cleanup() {
        System.out.println("🧹 快取已清除");
    }
}
```

### 用法 B：@Bean(initMethod, destroyMethod)（適合第三方類別）

```java
@Configuration
public class AppConfig {

    @Bean(initMethod = "init", destroyMethod = "cleanup")
    public CacheService cacheService() {
        return new CacheService();
    }
}
```

### 術語表

| 術語 | 定義 |
|------|------|
| @PostConstruct | Bean 建立且注入完成後自動執行的初始化標注（jakarta.annotation） |
| @PreDestroy | 容器關閉前自動呼叫的清理標注；prototype 不觸發 |
| Lifecycle（生命週期） | Bean 從建立到銷毀的完整過程 |
| initMethod / destroyMethod | @Bean 屬性，字串形式指定初始化／清理方法名，適合第三方類別 |
