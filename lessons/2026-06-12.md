## IoC 與依賴注入：為什麼不要自己 new · 第 7 步

### @Bean + @Configuration — 注入你自己不擁有的類別

當第三方 library 的 class 你無法加 @Component 時，在 `@Configuration` class 中用 `@Bean` 方法手動登記。Spring 啟動時執行該方法，把回傳物件放進 IoC 容器；使用方照常建構子注入，與 @Component 用法完全相同。

```java
// 設定檔：手動登記 Bean
@Configuration
public class AppConfig {

    @Bean
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}

// 使用方：建構子注入，和 @Component 沒有差別
@Service
public class WeatherService {
    private final RestTemplate restTemplate;

    public WeatherService(RestTemplate restTemplate) {
        this.restTemplate = restTemplate;
    }
}
```

### 術語表

| 術語 | 定義 |
|------|------|
| @Configuration | 標記此 class 為設定檔，Spring 掃描並執行其中所有 @Bean 方法 |
| @Bean | 標在方法上；Spring 啟動時呼叫，把回傳物件放進 IoC 容器，方法名即 Bean 預設名稱 |
| RestTemplate | Spring 內建 HTTP 客戶端，本身沒有 @Component，是 @Bean 登記的典型案例 |

### 核心原則

- 自己的 class → `@Component`（或 `@Service` / `@Repository` / `@RestController`）
- 別人的 class → `@Configuration` + `@Bean` 方法登記
- Spring 兩種都認，統一放進 IoC 容器，注入方式完全相同
