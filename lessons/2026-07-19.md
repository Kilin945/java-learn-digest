## Starter 依賴：spring-boot-starter-web 幫你帶了什麼 · 第 1 步

### 概念：什麼是 Starter

單點（à la carte）依賴的問題：在 `build.gradle` / `pom.xml` 裡一條一條加函式庫（library），要自己確認版本相容性，容易踩到「相依地獄」。

Spring Boot 提供 **Starter**：官方幫你組好、測過版本相容性的一整包依賴（dependency）集合。加一行 = 加一整組互相搭配好的函式庫。

`spring-boot-starter-web` 就是「開發網頁 / REST API」專用的 Starter。

```gradle
// build.gradle
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-web'
}
```

今天只要記住：**Starter 不是一個功能，而是一包已經選好版本、彼此相容的依賴清單**。下一步會拆開這個套餐，看看裡面實際裝了哪些東西（例如內建網頁伺服器、JSON 處理工具等）。

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Starter | 起手套餐 | Spring Boot 官方組好、測過版本相容性的一組依賴集合 |
| Dependency | 依賴 | 專案要用到的別人寫好的程式碼包（library） |
| Classpath | 類別路徑 | Java 執行時查找可用類別（class）的清單，@ConditionalOnClass 就是檢查這份清單 |
