## @RestController 與 @RequestMapping 家族 · 第 4 步

### 概念：Combining Class-Level and Method-Level Mapping（共同前綴 + 房號）

- `@RequestMapping` 貼在 **class** 上時，代表整個 controller 的「共同前綴路徑」（大門地址）。
- 貼在 **method** 上的 `@GetMapping`、`@PostMapping` 等捷徑標籤，路徑會接在前綴後面。
- 最終網址 = class 前綴 + method 路徑。

### 範例程式碼

```java
@RestController
@RequestMapping("/api/users")   // 大門地址
public class UserController {

    @GetMapping                 // 完整路徑：/api/users
    public String getAllUsers() {
        return "回傳所有使用者列表";
    }

    @GetMapping("/{id}")         // 完整路徑：/api/users/{id}
    public String getUserById() {
        return "回傳單一使用者資料";
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Common Prefix Path | 共同前綴路徑 | 貼在 class 上的 @RequestMapping 路徑，controller 內所有方法都會先接上這段 |
| Path Concatenation | 路徑合併 | class 前綴路徑 + method 路徑 = 最終完整網址 |

### 本主題小結

這個系列教完了 @RestController 家族的核心用法：
1. `@RestController`：讓類別變成專門處理 HTTP 請求、回傳值直接當 response body 的「外帶窗口」。
2. `@RequestMapping`：貼在方法（或 class）上的號碼牌，用 value + method 指定對應的網址與請求方式。
3. `@GetMapping`/`@PostMapping`/`@PutMapping`/`@DeleteMapping`：對應四種 HTTP 動作的捷徑寫法。
4. class 前綴 + method 路徑可以合併，讓同一群功能的網址不用重複打字。
