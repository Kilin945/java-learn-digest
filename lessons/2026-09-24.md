## Actuator：健康檢查與指標 · 第 3 步

### 概念：Drilling into a Single Metric

`/actuator/metrics` 回傳的是「有哪些指標」的名稱清單，不是實際數值。要看某一支指標的實際讀數，要接上指標名稱：`/actuator/metrics/{name}`。

回傳內容包含：
- `baseUnit`：這個數字的單位（例如 bytes、seconds）
- `measurements`：實際的統計值（`statistic` + `value`）
- `availableTags`：可用來篩選的維度，例如 `?tag=area:heap`

### 程式碼

```
GET /actuator/metrics
{
  "names": [
    "jvm.memory.used",
    "http.server.requests",
    "system.cpu.usage"
  ]
}

GET /actuator/metrics/jvm.memory.used
{
  "name": "jvm.memory.used",
  "baseUnit": "bytes",
  "measurements": [
    { "statistic": "VALUE", "value": 84315136 }
  ],
  "availableTags": [
    { "tag": "area", "values": ["heap", "nonheap"] }
  ]
}
```

篩選範例：`/actuator/metrics/jvm.memory.used?tag=area:heap`

### 術語表

| 術語 | 定義 |
|---|---|
| Metric（指標） | App 內部某個會變動的數字，例如記憶體用量、API 被呼叫次數 |
| baseUnit（基礎單位） | 這個數字的計量單位，例如 bytes、seconds |
| Tag（維度標籤） | 同一個指標底下可再細分的分類，例如記憶體可分 heap／nonheap |

### 主題總結（3 步完結）

1. `/actuator/health` 回傳 UP/DOWN，不用寫程式碼
2. `management.endpoints.web.exposure.include=health,info,metrics` 打開更多端點
3. `/actuator/metrics/{name}` 查單一指標實際數值
