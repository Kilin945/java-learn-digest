## Spring Security 入門：認證與授權概念 · 第 1 步

### Authentication vs Authorization

用辦公大樓比喻：
- **Authentication（認證）**：大門口警衛看員工證，確認「你是誰」。
- **Authorization（授權）**：門禁卡只能刷開特定樓層，決定「你能做什麼」。
- 順序固定：先認證，再授權。

### 對應的 HTTP 狀態碼

```
GET /api/orders/42

(1) 沒帶身分證明 / 帳密錯誤
    -> 401 Unauthorized   （認證失敗：不知道你是誰）

(2) 身分OK，但一般會員想打 DELETE /api/admin/users/7
    -> 403 Forbidden      （授權失敗：知道你是誰，但不能做）
```

注意：401 英文叫 Unauthorized，但實際指的是「認證」失敗。

### 一句話帶走
Authentication = 你是誰（401）；Authorization = 你能做什麼（403）；先認證再授權。

### 術語表
| 術語 | 中文 | 定義 |
|---|---|---|
| Spring Security | Spring 安全框架 | 處理登入驗證與權限控管的官方框架 |
| Authentication | 認證 | 確認你是誰 |
| Authorization | 授權 | 確認你能做什麼 |
| 401 Unauthorized | 未認證 | 不知道你是誰 |
| 403 Forbidden | 禁止存取 | 知道你是誰但沒權限 |
