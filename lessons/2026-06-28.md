## Bean 的 scope 與生命週期 · 第 2 步

### 概念：Prototype Scope

Spring Bean 的 **prototype scope** 讓每次注入（或向容器請求）時都建立一個**全新的實例**，與 singleton（所有人共用同一個）完全相反。

**生活比喻**
- 🖼️ singleton = 辦公室共用白板，大家寫的東西互相影響
- 📒 prototype = 個人便條本，每人拿到自己那本，互不干擾

### 宣告方式

```java
@Component
@Scope("prototype")   // 每次注入都產生新實例
public class ShoppingCart {
    private List<String> items = new ArrayList<>();

    public void addItem(String item) {
        items.add(item);
    }
    public List<String> getItems() { return items; }
}
```

### 注入行為

```java
@Service
public class CheckoutService {
    @Autowired
    private ShoppingCart cart;  // CheckoutService 專屬的新物件
}

@Service
public class CartService {
    @Autowired
    private ShoppingCart cart;  // CartService 專屬的另一個全新物件（不同實例）
}
```

### 術語表

| 術語 | 中文 | 白話定義 |
|------|------|----------|
| prototype | 原型 | 每次注入都建立全新實例的 scope |
| stateful | 有狀態的 | 物件內部有記憶（如 List、計數器），不適合多人共用 |
| @Scope | scope 標注 | 宣告 Bean 生命週期策略的 Spring 標注 |

### 使用時機

- ✅ 適合：購物車、使用者表單、有個別狀態的物件
- ❌ 不適合：無狀態的工具類（用 singleton 效能更好，避免頻繁 new）
