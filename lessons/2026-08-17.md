## 統一例外處理：@RestControllerAdvice · 第 2 步

### 概念
把「處理例外的邏輯」從各個 Controller 搬到一個獨立的 class，並在該 class 上標註 `@RestControllerAdvice`，讓它成為整個專案共用的全域例外處理中心。實際負責處理某一種例外的是標在方法上的 `@ExceptionHandler(某例外類別.class)`——Spring 偵測到該例外被丟出時，會自動呼叫對應的方法，Controller 本身完全不需要 try-catch。

比喻：以前每個房間（Controller）自己接電話處理客訴，現在整棟大樓只有一個總機（`@RestControllerAdvice` class），電話統一轉進來由專員（`@ExceptionHandler` 方法）處理。

### 程式碼
```java
@RestControllerAdvice          // 全域例外處理中心
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)  // 只接這種電話
    public String handleNotFound(ResourceNotFoundException e) {
        return "找不到資源：" + e.getMessage();
    }
}
```

今天先求看懂結構，回傳格式（現在只回一段文字）之後會再優化成正式的錯誤物件。

### 術語表
- **@RestControllerAdvice**（全域例外處理標註）：標在獨立 class 上，宣告這裡是整個專案共用的例外處理中心。
- **@ExceptionHandler**（例外處理方法標註）：標在方法上，指定專門處理哪一種例外類別，出現該例外時 Spring 自動呼叫此方法。
- **class**（類別）：組織程式碼的容器，可想成一張設計圖或檔案夾。
