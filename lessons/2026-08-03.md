## @RestController 與 @RequestMapping 家族 · 第 3 步

### 概念：@GetMapping 與家族捷徑

昨天學到 @RequestMapping 要自己填 `value`（路徑）與 `method`（HTTP 動作）。今天學到的是它的「捷徑版本」：

- `@GetMapping` = `@RequestMapping(method = RequestMethod.GET)` → 查詢資料
- `@PostMapping` = `@RequestMapping(method = RequestMethod.POST)` → 新增資料
- `@PutMapping` = `@RequestMapping(method = RequestMethod.PUT)` → 更新資料
- `@DeleteMapping` = `@RequestMapping(method = RequestMethod.DELETE)` → 刪除資料

這些捷徑功能上完全等價於 @RequestMapping，只是可讀性更好，是業界慣用寫法。

### 程式碼範例

```java
// 較囉唆的寫法
@RequestMapping(value = "/hello", method = RequestMethod.GET)
public String hello() {
    return "Hello!";
}

// 捷徑寫法（今天教的）
@GetMapping("/hello")
public String hello() {
    return "Hello!";
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| @GetMapping | @RequestMapping(method=GET) 的捷徑，用於查詢 |
| @PostMapping | @RequestMapping(method=POST) 的捷徑，用於新增 |
| @PutMapping | @RequestMapping(method=PUT) 的捷徑，用於更新 |
| @DeleteMapping | @RequestMapping(method=DELETE) 的捷徑，用於刪除 |
