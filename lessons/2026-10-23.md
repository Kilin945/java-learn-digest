## G1 · 給一個 Integer[]（裡面可能有 null），把它排序。盡量不用內建 function

### 第 0 輪：題目與答案

**答案**：動手前先問「null 放前面還是後面？」（題目故意沒說）。三步：

1. **分離**：原地把非 null 往前搬，n 變成非 null 的個數，額外空間 O(1)。
2. **排序**：只對前 n 個做插入排序；null 已被擠到後面，比較碰不到 null，不需要 null 判斷。
3. **補尾巴**：n 之後補回 null。

null 要放前面，就在第①步從尾端往前填。

**錨點**：電文欄位過濾與組回應就是第①③步，缺的只有第②步手寫排序。

### 第 1 輪（比喻）：為什麼要先分離 null？

像隊伍裡混著空位，空位沒有身高沒法比，所以先請空位站最後面。程式裡 null 沒有大小可比，拆箱時會 NPE。「null 放哪邊」是規格，不是實作細節。

### 第 2 輪（流程）：arr[n++] = v 邊讀邊寫會蓋掉資料嗎？

不會，寫的位置 n 永遠不會超過讀的位置 i（n ≤ i）。n 兼任「下一個寫入位置」與「非 null 個數」。

```
起始        [3, null, 1, null, 2]   n=0
讀到 3      寫 arr[0]=3             n=1
讀到 1      寫 arr[1]=1             n=2
讀到 2      寫 arr[2]=2             n=3
結束        [3, 1, 2, null, 2]      n=3   (尾巴殘留舊值 2)
③ 補 null   [3, 1, 2, null, null]
```

### 第 3 輪（程式碼＋比喻）：插入排序

像理撲克牌：左邊是排好的，新牌存進 key，從右往左把比 key 大的往右挪一格（騰空位，不是交換），最後把 key 放進空位。

```
i=1, key=1:  [3, 3, 2] → 放 key → [1, 3, 2]
i=2, key=2:  [1, 3, 3] → 放 key 到 arr[1] → [1, 2, 3]
```

時間 O(n²)，空間 O(1)。

### 第 4 輪（反例）：int key = arr[i] 為什麼不會 NPE？

這行有自動拆箱。迴圈範圍是 i < n，那段在第①步後保證非 null。反例：不分離直接排整個陣列，i=1 時 arr[1] 是 null，拆箱就 NPE。分離是用資料整理換掉到處防禦 null。

### 第 5 輪（錨點）：跟平常工作的關係

過濾欄位＝第①步，組回應補齊固定結構＝第③步；只多一個沒親手寫過的零件（排序）。

### 第 6 輪（面試追問）

- **null 放前面怎麼改？** 從尾端往前填，再只排尾端非 null 區間，最後前面補 null；重點是先問清楚。
- **為什麼不會 NPE？** 迴圈範圍 i < n 限定在非 null 區間。
- **為什麼不用 Arrays.sort + Comparator.nullsLast？** 題目考的就是不用內建；要補一句「正式專案我會用內建的」。

### 參考程式碼

```java
Integer[] sort(Integer[] arr) {
    if (arr == null) return arr;

    // ① 分離：非 null 往前搬，n 變成非 null 的個數
    int n = 0;
    for (Integer v : arr) if (v != null) arr[n++] = v;

    // ② 插入排序，只排前 n 個
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) { arr[j + 1] = arr[j]; j--; }
        arr[j + 1] = key;
    }

    // ③ 尾巴補 null（null 放後面的版本）
    for (int i = n; i < arr.length; i++) arr[i] = null;
    return arr;
}

// 正式專案寫法
Arrays.sort(arr, Comparator.nullsLast(Comparator.naturalOrder()));
```

### 今日一句話

先問 null 放哪邊，再分離、只排非 null 的前 n 個、補回 null；先趕走 null，排序就不碰 null，拆箱不會 NPE。

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| In-place | 原地 | 直接在原陣列上改，不另開新陣列 |
| Insertion Sort | 插入排序 | 像理撲克牌，每次把新牌插到正確位置 |
| Auto-unboxing | 自動拆箱 | Integer 自動轉 int，null 時丟 NPE |
| NPE | 空指標例外 | 對 null 呼叫方法或拆箱時發生 |
| O(n²) / O(1) | 時間／空間複雜度 | 步數隨資料量成長的速度／額外記憶體用量 |
| nullsLast | null 排最後 | Comparator 內建工具，讓 null 排在其他值之後 |
