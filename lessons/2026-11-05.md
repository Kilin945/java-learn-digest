## A1 第 1 篇 · 自己 new 的問題 vs 交給 Spring 容器建立與組裝

**題目：IoC / DI 是什麼？好處是什麼？**

### 題目在問什麼
- IoC（控制反轉）：建立物件的控制權從自己的程式碼轉給容器。
- DI（依賴注入）：容器建好物件後送到你手上。
- 要答到：IoC 是什麼、DI 是什麼、好處是什麼。本篇只講自己 new 的問題與容器接手建立與組裝。

```java
// 依賴：A 要運作需要 B，B 就是 A 的依賴
// 輸入：OrderService 要呼叫 PaymentClient
// 問題：PaymentClient 由誰建立？
//   (a) OrderService 自己 new
//   (b) 別人建好交給它  -> 控制權反轉
```

### 解題思路
1. 先定義依賴與「誰負責建立」。
2. 看自己 new 的痛點（本篇）。
3. 看容器接手建立與組裝（本篇）。
4. 容器怎麼注入（第 2 篇）。
5. 好處：換實作、塞假物件測試（第 2 篇）。

### 答案
IoC 是把建立與組裝物件的工作交給 Spring 容器，你只宣告需要什麼。

```java
// 簡化示意：自己 new
public class OrderService {
    private final PaymentClient client = new PaymentClient("https://pay.example/api", 3000);
}

// 典型寫法（簡化）：交給容器
@Service
public class OrderService {
    private final PaymentClient client;
    public OrderService(PaymentClient client) { this.client = client; }
}
```

### 第 1 輪（釐清）：Spring 容器和 Bean 到底是什麼？
```java
// 容器啟動時：① 掃描標籤 ② 建立物件 ③ 存進倉庫
// Bean = 被容器建立並管理的物件；容器 = ApplicationContext
@Service
public class PaymentClient { }
// 簡化示意：倉庫.put(PaymentClient.class, new PaymentClient());
```

### 第 2 輪（反事實）：沒有容器，自己 new 會壞在哪？
```java
// 壞處 1：寫死實作，換實作要改原始碼
private final PaymentClient client = new PaymentClient(...);
// 壞處 2：組裝鏈變長，A 必須知道 C 怎麼建
DataSource ds = new DataSource(url, user, pwd);
Repo repo = new Repo(ds);
PaymentClient pc = new PaymentClient(repo);
OrderService svc = new OrderService(pc);
// 壞處 3：沒人管份數，各自 new 就各開一份（例如連線池）
```

### 第 3 輪（連結經驗）：我的 Service @Autowired、建構子注入、anki-forge 的 configurable service bean
```java
// 典型寫法（簡化）
@Service
public class SomeService {
    @Autowired
    private SomeRepo repo;
}

@Service
public class SomeService {
    private final SomeRepo repo;
    public SomeService(SomeRepo repo) { this.repo = repo; }
}
// 兩種寫法都沒有 new，建立權在容器手上
```

### 為什麼要懂
換付款服務時，若每個類別都自己 new，要全專案搜尋逐一修改；理解建立權在容器，才知道改一處設定即可，也知道「找不到 Bean」該往哪查。

### 結論
IoC 就是不再自己 new，改成宣告需求、由容器建立與組裝。

### 術語表
| 術語 | 定義 |
|---|---|
| IoC | 控制反轉：建立物件的控制權轉給容器 |
| DI | 依賴注入：容器把需要的物件送進來（第 2 篇） |
| 依賴 | A 要運作所需要的物件 B |
| 容器 | 啟動時建立並管理物件的倉庫（ApplicationContext） |
| Bean | 被容器建立並管理的物件 |
| @Service | 標籤：請容器幫我建這個類別的物件 |
