## @RestController 與 @RequestMapping 家族 · 第 2 步

### 概念

昨天教過 `@RestController` 是整間店的「外帶總窗口」，但一個窗口通常賣不只一種東西——顧客得先看「號碼牌」才知道去哪一格拿餐點。

`@RequestMapping` 就是貼在方法上的號碼牌：告訴 Spring Boot「當有人連到某個網址（value，例如 `/hello`），且使用某種請求方式（method，例如 GET）時，就叫這個方法處理」。沒有號碼牌的方法，Spring 不知道要對應哪個網址。

### 程式碼

```java
@RestController
public class HelloController {

    @RequestMapping(value = "/hello", method = RequestMethod.GET)
    public String sayHello() {
        return "哈囉，這是你的第一個 API 回應！";
    }
}
```

瀏覽器打開 `http://localhost:8080/hello`，會直接看到這句字串（因為 `@RestController` 讓回傳值直接變成 response body）。

之後會學到更簡短的 `@GetMapping`，其實就是 `@RequestMapping(method = GET)` 的懶人版。

### 術語表

| 術語 | 定義 |
|---|---|
| @RequestMapping | 貼在方法上，指定該方法要處理哪個網址、哪種請求方式 |
| value / path | 網址中跟在網域後面的部分，例如 `/hello` |
| method | 請求方式，GET 代表「只是要看資料」 |
| RequestMethod.GET | Java 裡代表「GET 請求」的固定寫法選項 |
