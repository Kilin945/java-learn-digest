## G1 第 3 篇 · 變形：null 改放前面怎麼寫；為什麼不用 Arrays.sort

**題目**：給一個 Integer[]（裡面可能有 null），把它排序。盡量不用內建 function。15 分鐘。

### 題目在問什麼
- Integer[] 的格子可以是 null，排序前要決定 null 放哪。
- 「內建 function」指 Arrays.sort、Collections.sort、stream().sorted() 等。
- 題目沒說 null 放前或後，要先問。今天做放前面。

```java
// 輸入
Integer[] in  = {3, null, 1, null, 2};
// 輸出（null 放前面）
Integer[] out = {null, null, 1, 2, 3};
```

### 解題思路
1. null 不能比大小，先分離。（第 1 篇）
2. 分離後前段無 null，用插入排序。（第 2 篇）
3. 最後把 null 補回指定一側。
4. **放前面只是方向相反：改 ① 搬移方向、② 範圍、③ 補 null 位置。（本篇）**
5. **能說清楚為什麼這題不用內建、正式專案用什麼。（本篇）**

### 答案
null 放前面：① 從尾端往前搬非 null，② 只排 [k, length)，③ 前 k 格補 null。

```java
Integer[] sortNullsFirst(Integer[] arr) {
    if (arr == null) return arr;

    // ① 從尾端往前搬；k = 非 null 區起點
    int k = arr.length;
    for (int i = arr.length - 1; i >= 0; i--)
        if (arr[i] != null) arr[--k] = arr[i];

    // ② 插入排序，範圍 [k, length)
    for (int i = k + 1; i < arr.length; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= k && arr[j] > key) { arr[j + 1] = arr[j]; j--; }
        arr[j + 1] = key;
    }

    // ③ 前 k 格補 null
    for (int i = 0; i < k; i++) arr[i] = null;
    return arr;
}
```

### 第 1 輪 · 釐清：「null 放前面」要改哪幾行？
只動三處，排序本身不變：

| | 放後面 | 放前面 |
|---|---|---|
| 非 null 區 | [0, n) | [k, length) |
| ① 搬移 | 由頭往後 arr[n++] = v | 由尾往前 arr[--k] = arr[i] |
| ② 排序範圍 | i 從 1 到 n，j >= 0 | i 從 k+1 到 length，j >= k |
| ③ 補 null | [n, length) | [0, k) |

### 第 2 輪 · 追原因：為什麼不用 Arrays.sort 配 nullsLast？
題目限制不給用內建。正式專案會用：

```java
Arrays.sort(arr, Comparator.nullsLast(Comparator.naturalOrder()));
Arrays.sort(arr, Comparator.nullsFirst(Comparator.naturalOrder())); // null 放前面
```
回答要有兩句：題目要求不用所以手寫；正式專案用內建（一行、經過驗證、O(n log n)）。

### 第 3 輪 · 比較：手寫插入排序 vs Arrays.sort
- 插入排序：最壞 O(n²)，近乎排好時接近 O(n)，額外空間 O(1)，null 要自己處理。
- Arrays.sort（物件陣列）：O(n log n)，穩定排序，null 交給 nullsFirst/nullsLast。
- 選法：正式專案、量不確定用內建；量很小或題目限制才手寫。

### 追問
1. **null 放前面怎麼改？** 分離時從尾端往前填，非 null 區為 [k, length)，前面補 null；動手前先問放哪邊。
2. **int key = arr[i] 的自動拆箱為什麼不會 NPE？** 迴圈只掃非 null 區，那段保證沒有 null。
3. **為什麼不用 Arrays.sort + nullsLast？** 題目考的就是不用內建；補一句「正式專案我會用內建」。

### 為什麼要懂
你每天做電文欄位過濾、組回應，已經在做 ① 和 ③。補上排序後，遇到「欄位可能是 null、要排序再回傳」就能判斷自己處理或交給 nullsFirst/nullsLast，需求沒說 null 擺哪時也知道要先問。

### 結論
null 放前面只是把分離、排序、補 null 的方向與範圍反過來，排序本身不用改。不用內建是題目限制，正式專案用 Arrays.sort 配 nullsFirst/nullsLast。

### 術語表
| 術語 | 白話定義 |
|---|---|
| Comparator | 「怎麼比兩個東西誰先誰後」的規則物件 |
| nullsFirst / nullsLast | 包在別的 Comparator 外，讓 null 一律排最前 / 最後 |
| 自動拆箱 | Integer 轉 int 時編譯器補 intValue()，對 null 會 NPE |
| 原地（in-place） | 只在原陣列上改，不另開同大小陣列 |
| 穩定排序 | 值相等的元素排完後維持原本先後 |
| O(n²) / O(n log n) | 資料量變 n 倍時時間成長的速度，前者慢得多 |
