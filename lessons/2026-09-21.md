## @DataJpaTest 等測試切片 · 第 4 步

### 概念：Test Slice 家族

`@DataJpaTest` 是 Spring Boot **test slice（測試切片）** 家族的其中一種。切片的共同邏輯：

> 只啟動你要測的那一層（樓層）相關的 Bean，其他層省略或換成假貨（Mock），讓測試跑得快、範圍小、不互相干擾。

常見切片：

| 註解 | 只啟動哪一層 | 用途 |
|---|---|---|
| `@DataJpaTest` | Repository + H2 | 測資料庫存取邏輯 |
| `@WebMvcTest` | Controller | 測 HTTP 路由、請求/回應 |
| `@JsonTest` | 無（純物件） | 測物件 ↔ JSON 轉換 |
| `@RestClientTest` | REST client 程式碼 | 測呼叫外部 API 的邏輯 |

### 程式碼對照

```java
@DataJpaTest              // 只蓋 Repository 那層 + H2
class MemberRepositoryTest { ... }

@WebMvcTest(MemberController.class)  // 只蓋 Controller 那層
class MemberControllerTest { ... }
```

### 術語表

- **Test Slice（測試切片）**：只啟動應用程式某一層相關 Bean 的測試設定。
- **@WebMvcTest（網頁層切片）**：只啟動 Controller 相關 Bean，測 HTTP 請求路由與回應。
- **@JsonTest（JSON 切片）**：只測物件與 JSON 互相轉換是否正確。
- **Mock（假物件）**：行為由測試程式指定的替身物件，取代還沒啟動的真實 Bean。

### 本主題累積重點（含今天）

1. `@DataJpaTest` 是 test slice，只啟動資料庫存取相關 Bean，預設用 H2，每個測試結束自動 rollback。
2. `TestEntityManager` 可手動塞假資料，搭配 AAA（Arrange-Act-Assert）結構驗證 Repository 方法。
3. `entityManager.persist()` 只是放進 Persistence Context，`persistAndFlush()` 才真的寫進資料庫，避免測試假陽性。
4. `@DataJpaTest` 只是切片家族一員，`@WebMvcTest`／`@JsonTest`／`@RestClientTest` 都遵循同一邏輯：只蓋要測的那層。
