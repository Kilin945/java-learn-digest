## MockMvc 測 Controller · 第 5 步

### 概念：Testing POST with a Request Body

之前教的都是 GET（查詢），今天教 POST（新增）。POST 請求要帶「request body（請求主體）」，就像寄掛號信除了地址還要放信件內容。

測試時要做兩件事：
1. `.contentType(MediaType.APPLICATION_JSON)`：告訴伺服器內容格式是 JSON。
2. `.content(json字串)`：放入實際內容。

Java 物件要先用 `ObjectMapper`（Jackson 函式庫提供的轉換工具）轉成 JSON 字串。

### 程式碼

```java
@WebMvcTest(UserController.class)
class UserControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    @MockitoBean
    private UserService userService;

    @Test
    void createUser_returnsCreated() throws Exception {
        User newUser = new User("Amy");
        when(userService.save(any())).thenReturn(newUser);

        mockMvc.perform(post("/users")
                .contentType(MediaType.APPLICATION_JSON)
                .content(objectMapper.writeValueAsString(newUser)))
            .andExpect(status().isCreated())
            .andExpect(jsonPath("$.name").value("Amy"));
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| request body（請求主體） | HTTP 請求裡夾帶資料的部分，POST/PUT 常用它送新增或修改的內容 |
| ObjectMapper（JSON 轉換器） | Jackson 提供，把 Java 物件與 JSON 字串互相轉換 |
| contentType（內容類型） | 宣告送出內容的格式，這裡用 MediaType.APPLICATION_JSON |
| status().isCreated()（201 狀態碼斷言） | 檢查回應狀態碼是否為 201，代表新增成功 |
