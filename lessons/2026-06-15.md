## Bean 是什麼：@Component / @Service / @Repository · 第 1 步

### 核心概念

- **Bean**：Spring 存進 IoC 容器的 Java 物件；應用程式共享同一個實例，不需要自己 new。
- **@Component**：貼在 class 上，告訴 Spring 在 Component Scan 時幫你建立該 class 的 Bean。
- **Component Scan**：Spring Boot 啟動時自動掃描 main class 同層及子 package，找到 @Component 就執行 `new ClassName()` 並存入容器。

### 比喻

> IoC 容器 = 倉庫；Bean = 倉庫裡存放的物品；@Component = 貼在物品上的「請幫我入庫」標籤。

### 程式碼範例

```java
import org.springframework.stereotype.Component;

@Component          // Spring 掃描到這個 class 時，自動 new 一個實例放進容器
public class GreetingService {

    public String greet(String name) {
        return "Hello, " + name + "!";
    }
}
```

Spring Boot 啟動 → Component Scan → 發現 @Component → `new GreetingService()` → 存進 IoC 容器。

### 術語表

| 術語 | 中文 | 說明 |
|------|------|------|
| Bean | 被管理的物件 | Spring 放進 IoC 容器裡的 Java 物件 |
| @Component | 元件標籤 | 讓 Spring 在 Component Scan 時自動建立並管理該 class 的 Bean |
| Component Scan | 元件掃描 | Spring Boot 啟動時自動掃描並登記 Bean 的過程 |
| IoC Container | IoC 容器 | Spring 存放所有 Bean 的「倉庫」 |

### 今日一句話

@Component = 告訴 Spring「幫我把這個 class 的物件放進倉庫，我要用時直接向你要」。
