## 衍生查詢 vs @Query · 第 1 步

### 概念：Derived Query Method（衍生查詢方法）

Spring Data JPA 可以靠「方法名稱」自動產生 SQL，不需要自己手寫查詢語法。規則是 `findBy` + 屬性名稱。

比喻：跟便利商店店員說「我要包裝紅色、裡面是牛奶的飲料」，店員自己去找對的貨架 —— 你不用自己寫查詢邏輯，Spring Data JPA 幫你翻譯成 SQL。

```java
public interface UserRepository extends JpaRepository<User, Long> {

    // 方法名稱 = 查詢條件，不用寫任何 SQL
    User findByUsername(String username);

}
```

只要宣告方法簽章，不用寫實作，Spring Boot 啟動時會自動產生真正可執行的查詢邏輯。

### 術語表

| 術語 | 定義 |
|---|---|
| Derived Query Method 衍生查詢方法 | 靠方法名稱命名規則自動產生 SQL 查詢，不用手寫查詢語法 |
| Repository 資料庫存取介面 | 程式和資料庫之間溝通的中間人介面 |
| SQL | 跟資料庫溝通、查詢或操作資料的語言 |

### 今日一句話
方法名稱本身就是查詢條件，Spring Data JPA 會幫你把它翻譯成 SQL。
