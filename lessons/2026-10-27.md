## G1 第 1 篇 · 先把 null 分出去:原地把非 null 往前搬,n 順手變成非 null 的個數

### ⭐ 給一個 Integer[](裡面可能有 null),把它排序。盡量不用內建 function。15 分鐘。

**題目在問什麼**

- Integer[]:裝 Integer 物件的陣列,格子可能是 null。
- 排序:由小到大,結果寫回同一個陣列。
- 不用內建 function:不能用 Arrays.sort、Collections.sort 等。
- 題目沒說的:null 排前還是排後?動手前要先問。本篇假設排後。
- 限制:15 分鐘。

```java
// 輸入
Integer[] in  = {3, null, 1, null, 2};
// 輸出(null 排後面)
Integer[] out = {1, 2, 3, null, null};
```

**解題思路**

1. 因為 null 不能比大小,所以先把 null 分出去。(本篇)
2. 因為 null 已被擠到後面,前 n 格全是數字,所以只對前 n 格排序。(第 2 篇)
3. 排完後尾巴補回 null。(後面篇章)

**答案**:用計數器 n 掃一遍,非 null 就寫到 arr[n] 再 n++;掃完前 n 格全是非 null,n 即非 null 個數,額外空間 O(1)。

```java
Integer[] arr = {3, null, 1, null, 2};

int n = 0;                      // 下一個寫入位置,也是已收個數
for (Integer v : arr)
    if (v != null)
        arr[n++] = v;

// 掃完:arr = {3, 1, 2, null, 2},n = 3
// 後 2 格是舊資料殘留,之後要補回 null
```

### 第 1 輪(釐清)arr[n++] = v 到底做了什麼?為什麼 n 同時是個數又是寫入位置?

```java
// arr[n++] = v; 等於
arr[n] = v;   // 先用現在的 n 當位置
n = n + 1;    // 再讓 n 加 1

// 追蹤 {3, null, 1, null, 2}:
// 3 → arr[0]=3, n=1;null 跳過;1 → arr[1]=1, n=2;null 跳過;2 → arr[2]=2, n=3
// 每收一個 n 加 1 → n 是個數;下一個要放的格子就是第 n 格 → n 是寫入位置

// 邊讀邊寫同一陣列安全:寫入位置 n 永遠 <= 讀取位置,寫到的格子都已讀過
```

### 第 2 輪(反事實)如果不先分離 null,直接插入排序會壞在哪?

```java
Integer[] arr = {3, null, 1};
int key = arr[1];  // arr[1] 是 null,自動拆箱呼叫 intValue() → NullPointerException

// 不分離的替代做法:每次比較前都加 null 判斷,還得決定 null 算大算小,程式變長又易錯
// 先分離後,前 n 格保證無 null,比較處完全不用想 null
```

### 第 3 輪(連結經驗)這在我每天做的電文欄位過濾裡長什麼樣子?

電文欄位過濾與組回應,就是這題的第 ① 步與第 ③ 步,缺的只有第 ② 步手寫排序。

```java
// 典型寫法(簡化):留下有值的欄位
List<String> kept = new ArrayList<>();
for (String f : fields)
    if (f != null) kept.add(f);

// 本題 ① 是同一個動作,差別是不開新 List,直接寫回原陣列前段,額外空間 O(1)
```

### 為什麼要懂

處理含 null 的陣列或欄位時,直接比較或排序,會在某筆資料剛好有 null 時才丟 NPE,測試資料沒涵蓋就上線才爆。先把 null 分出去,讓後面的程式只面對有值的資料,是整理資料常用的做法。

### 結論

排序前先用 arr[n++] = v 把非 null 往前搬,n 同時是個數與寫入位置,null 就不會進到比較的環節。

### 術語表

| 術語 | 定義 |
|---|---|
| Integer[] | 裝 Integer 物件的陣列,每格可為數字或 null |
| null | 這格沒有物件;沒有大小,不能呼叫方法 |
| 自動拆箱 | Integer 塞進 int 時自動呼叫 intValue();null 會丟 NPE |
| NPE | NullPointerException,對 null 呼叫方法或拆箱時丟出 |
| 原地(in-place) | 直接改原陣列,不另開新陣列 |
| 額外空間 O(1) | 多用的記憶體是固定幾個變數,不隨陣列長度增加 |
| n++ | 先用 n 的目前值,再加 1 |
