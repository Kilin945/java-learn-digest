# ── DBS 投遞前優先序 ──
G1-1｜先把 null 分出去：原地把非 null 往前搬，n 順手變成非 null 的個數
G1-2｜手寫插入排序，只排前 n 個；int key = arr[i] 為什麼不會 NPE
G1-3｜變形：null 改放前面怎麼寫；為什麼不用 Arrays.sort
B8-1｜interface＝約定「能做什麼」，一個類別可以實作多個
B8-2｜abstract class＝半成品骨架：共用流程寫在父類別，差異留給子類別（電文解析骨架）
B8-3｜Java 8 有 default method 之後，abstract class 還剩什麼：欄位、建構子、單一繼承
B9-1｜兩條執行緒兩把鎖：一段跑了就卡死的 code
B9-2｜死結的四個條件；固定上鎖順序、tryLock 逾時來解
B9-3｜怎麼查：jstack 抓 thread dump，怎麼讀出卡在哪兩把鎖
A1-1｜自己 new 的問題 vs 交給 Spring 容器建立與組裝
A1-2｜容器怎麼把依賴注入進來；測試時換成假物件
A7-1｜Controller 外面那一圈：web.xml／XML 設定／WAR＋外部 Tomcat vs @SpringBootApplication／starter／內嵌 Tomcat
A7-2｜自動配置怎麼運作：@ConditionalOnClass、@ConditionalOnMissingBean；自己的設定為什麼優先
B1-1｜HashMap 怎麼找東西：hashCode 找桶、equals 比對；只覆寫 equals 會出什麼 bug
B1-2｜拿會變的欄位算 hashCode：放進 Set 後改欄位就再也找不到
B4-1｜heap／stack／Metaspace 各放什麼，用一段 code 對應
B4-2｜OOM 常見成因：靜態 Map 忘了清、沒上限的快取、沒關的串流
B4-3｜怎麼查 OOM：HeapDumpOnOutOfMemoryError 怎麼開、heap dump 怎麼讀；Metaspace OOM 跟 heap OOM 的差別
B6-1｜String 不可變：迴圈裡相加的代價；改用 StringBuilder（電文 FILL 補齊組字串）
B6-2｜StringBuffer 的同步差在哪；String 為什麼要設計成不可變

# ── A Spring 核心 ──
A2-1｜欄位注入 vs 建構子注入：測試時 new 不出來、依賴藏起來
A2-2｜建構子注入的 final；循環依賴時啟動就失敗為什麼是好事
A3-1｜Bean 生命週期：建構 → 注入 → @PostConstruct → @PreDestroy
A3-2｜scope：singleton／prototype／request；singleton 裡注入 prototype 只會注入一次
A4-1｜沒有 AOP 時：交易、log、權限檢查在每個方法重複寫
A4-2｜動態代理怎麼包住方法：手寫一個 proxy 示意；@Transactional、@Secured 就是這樣做的
A5-1｜同類內部呼叫（self-invocation）為什麼不會觸發 @Transactional
A5-2｜其他失效情況：非 public、例外被自己吃掉、checked 例外預設不回滾；各自怎麼解
A6-1｜一個請求進來：DispatcherServlet → HandlerMapping → 你的 Controller 方法
A6-2｜參數怎麼變成物件（@RequestBody）、回傳值怎麼變成 JSON
A6-3｜攔截器 vs Filter；@ControllerAdvice 統一處理例外
